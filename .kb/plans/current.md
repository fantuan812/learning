## 范围

PR14、PR15、PR16 已完成身份关系与 306 篇核心正文迁移。本批不再搬迁核心正文，收敛旧导航与维护规则，并校正标准库内容。

- 新增八域、UE 源码阅读、端到端案例共 10 条路线，保留旧入口中的学习次序、练习、边界和版本要求；只链接唯一正文
- 退役下表 52 个已被路线替代的导航页。7 个被书籍原文引用的 README 留在原路径作为短入口；源码原始总索引保留叙述、日期与代码，只精确修正 8 处链接
- 工作日志、日期、附件与所有已有书籍、PDF、图片、读书笔记、相关工具按基线保全；不以 Git 历史替代当前可读原件
- 更新知识图、架构、taxonomy 兼容指针及写作/维护规则，旧分类不再接受新正文；必要自动化、许可与用户设备设置保留
- 修正 C++ 异常与标准库正文 §3.1 的 expected 内嵌存储、载荷资源、布局与异常边界；新增可执行实验、原始输出与 CI。其他节及成熟度不变
- 生成式索引不再硬编码更新日期；作者正文日期不改。manifest 在内容与导航收敛后机械重建
