## 分类简介

### 物理系统在 UE 中的定位

物理系统负责回答"游戏世界里物体怎么动、怎么撞、怎么碎"这三个问题，是玩法可信度与表现力的底层支撑。UE5 的物理系统以自研的 **Chaos** 物理引擎为核心，覆盖**刚体动力学**（质量/力/冲量驱动的运动）、**碰撞检测**（通道、事件、射线查询）、**物理约束**（关节、驱动、悬挂）与**物理驱动动画**（布娃娃、物理资产、布料、物理动画混合）四大领域。

学习物理系统的本质是理解一条流水线：

```mermaid
flowchart LR
    A[游戏逻辑<br/>施加力/冲量/约束] --> B[Chaos 物理场景<br/>FPhysScene 求解]
    B --> C[碰撞检测<br/>宽相位 + 窄相位]
    C --> D[求解器<br/>接触/约束求解]
    D --> E[组件变换更新<br/>Transform 同步]
    E --> F[表现层<br/>渲染/动画/音效反馈]
```

## 每篇一句话简介

- **01-Chaos物理引擎概览**：先把"物理引擎是什么、在 UE 里怎么跑"讲透——从 PhysX 到 Chaos 的演进、物理场景结构、多线程模型、刚体运动的基本方程，这是理解后面所有物理功能的地基。
- **02-碰撞检测与物理材质**：讲"物体之间怎么判定碰撞、怎么回应"——通道/预设/响应矩阵决定谁能撞谁，Hit 与 Overlap 事件是玩法接入点，物理材质决定摩擦与弹性，射线/扫描是命中判定与探测的常用手段。
- **03-物理约束与关节**：讲"怎么把多个刚体连接起来"——铰链/球形/棱柱关节、自由度锁定与约束驱动器，以及悬挂系统、Chaos 破坏系统的断裂连接和约束的性能成本。
- **04-布娃娃与物理动画**：讲"物理如何接管/辅助动画"——死亡布娃娃、物理资产工具链、布娃娃与动画的混合过渡、Chaos Cloth 布料模拟，以及运动学刚体与物理控制组件。
- **05-Chaos破坏系统与Field**：讲"物体怎么碎"——Geometry Collection 资产与层级碎块、Fracture 工具链、Chaos Solver 断裂求解、Field System 力场驱动与破坏事件接入玩法。

## 学习顺序建议

1. **入门（先建立整体观）**：先读 `01-Chaos物理引擎概览`，搞清楚物理场景、线程与刚体动力学框架，不深入细节；
2. **核心玩法（最常用）**：再读 `02-碰撞检测与物理材质`，碰撞通道与射线检测是日常开发出现频率最高的物理知识；
3. **进阶（机械与机关）**：然后读 `03-物理约束与关节`，门、摇杆、车辆悬挂、破坏场景都依赖约束；
4. **表现（动画与物理结合）**：最后读 `04-布娃娃与物理动画`，这部分依赖前面对刚体与约束的理解，也是"让角色死得真实/衣服会飘"的关键；
5. **进阶（破坏与力场）**：再读 `05-Chaos破坏系统与Field`，可破坏掩体、爆炸冲击、碎块飞散都依赖 Geometry Collection 与 Field System；
6. **实践建议**：每读完一篇，在 UE5 编辑器里做一个 10 分钟小实验（扔球、调碰撞预设、搭个摇杆、激活布娃娃、炸一堵墙），比纯记忆有效得多。
