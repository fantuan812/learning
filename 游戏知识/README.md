## 5. 领域边界与跨域协作规范

为保持知识库低冗余、高内聚，本域与相邻技术领域遵循严格的职责划分：

- **客户端与引擎专有特性留在本域**：所有 UE API 调用、引擎组件装配、编辑器工作流、UObject 生命周期均在 `游戏知识/` 展开。
- **通用计算机与工程底座下沉**：不在此重复讲解 C++ 标准虚表对齐、Linux epoll 原理或 TCP 拥塞控制，统一引用 [00-计算机与工程基础](../00-计算机与工程基础/README.md)。
- **服务端权威裁决后移**：Dedicated Server 进程的云端容器编排、长连接网关、持久化一致性与分布式事务属于 [游戏服务端](../游戏服务端/README.md)。
- **通用算法与数学抽象解耦**：A* 堆优化、四元数插值数学公式、KD-Tree 空间索引等通用算法归入 [游戏算法](../游戏算法/README.md)。
- **通用 AI 决策模型归入 AI 域**：纯数学的 Utility 效用曲线、GOAP A* 空间规划属于 [游戏AI](../游戏AI/README.md)；本域聚焦 UE BehaviorTree、EQS 与 StateTree 组件实现。
- **质量与性能回归放入质量域**：Gauntlet 自动化驱动、DS 压测 Bot 机器人属于 [游戏测试与质量](../游戏测试与质量/README.md) 与 `evidence/`。

## 6. 撰写规范与版本基准

- **引擎版本基准**：Unreal Engine 5.8.0（`CL55116800`，分支 `++UE5+Release-5.8`）。
- **文档标准结构**：核心概念 → 原理与数据结构详解 → C++ 源码实现与示例 → 性能预算与最佳实践 → 常见踩坑与排障。
- **图表辅助**：复杂对象关系、网络时序与管线流程强制使用 Mermaid 图或清晰 ASCII 架构图表达。
- **无断链原则**：每篇正文末尾需保留结构化的“关联知识与前置/后置专题”，确保知识网络全连通。
