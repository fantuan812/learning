## 学习路径

1. 先建立整体观：`01-架构与网络/01-服务器架构模式` → `01-架构与网络/03-帧同步与状态同步`
2. 再掌握基础设施：`01-架构与网络` 其余篇目（网络、消息、并发）
3. 然后深入数据与工程化：`02-数据与业务`（存储 → 缓存 → 分布式 → 安全 → 运维）
4. 再学习平台可靠性：`04-平台与可靠性/01-鉴权限流幂等灾备与可观测性`（身份 → 流量 → 状态 → 灾备 → 观测 → 灰度）
5. 最后落地业务层：`03-业务系统设计`（背包 → 战斗结算等典型系统），把可靠性约束带入业务设计。
