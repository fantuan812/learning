# 04 平台与可靠性

> 面向在线游戏服务端平台工程的 P1 可靠性专题：把身份、流量、状态、数据、发布和观测串成可验证的运行闭环。

## 分类简介

本分类讨论跨业务模块的可靠性底座，不绑定某家云厂商、容器平台、数据库或消息中间件。
文中的 YAML、SQL、伪代码和指标名均是可改造的示意；当前项目是否已有对应基础设施，必须以实际仓库、部署清单和运行证据为准。

## 学习路径

1. 先读 [01-鉴权限流幂等灾备与可观测性.md](01-鉴权限流幂等灾备与可观测性.md) 的事实边界、输入输出责任表和失败路径，建立可靠性问题地图。
2. 再按“身份与权限 → 网关与限流 → 幂等与状态机”阅读，先把一次请求如何被安全、可控地处理讲清楚。
3. 接着学习“迁移与灾备 → 服务治理与缓存 → 可观测性与容量”，把单次操作扩展到数据和平台生命周期。
4. 最后阅读“灰度发布、测试矩阵、FAQ、关联阅读”，将方案转成版本门禁、演练脚本和事故复盘行动项。
5. 与 [01-架构与网络](../01-架构与网络/README.md)、[02-数据与业务](../02-数据与业务/README.md)、[03-业务系统设计](../03-业务系统设计/README.md) 交叉阅读，按实际业务的权威边界落地。
