# 05-UE Dedicated Server 平台化

> 面向游戏服务端平台团队，说明 UE Dedicated Server 实例如何被构建、分配、运行、观测、摘流量和回收。

## 分类定位

本分类把 UE Dedicated Server 进程放进匹配、分配器、调度器、房间服务和发布平台的上下文中。
它不把 UE 引擎内置成一个云平台，也不把 Agones、Kubernetes 或 Amazon GameLift Servers 的能力冒充 UE API。
UE 相关事实以现有 UE5.8 源码专题和工具链专题为边界；平台部分用中立契约、适配边界和示意伪代码表达。

## 版本与事实边界

- 版本基线：UE5.8.0 / CL55116800 / ++UE5+Release-5.8
- 最后更新：2026-08-06
- 适用范围：专用服务器实例生命周期、分配契约、部署适配、健康检查、观测、安全和发布回滚。
- 事实边界：项目 Target、第三方 API、云资源和真实容量必须由项目现场核对。

4. 最后结合 [游戏服务端 04-平台与可靠性](../04-平台与可靠性/README.md)，落实鉴权、幂等、灾备、观测和灰度。

7. 会话注册与断线重连实现参见 [03-DS会话注册与重连实现](<03-DS会话注册与重连实现.md>)。

## 阅读约定

- “UE5.8 事实”只指已标注源码/官方来源的引擎行为。
- “平台方案”表示项目可以采用的接口、状态机或部署适配，不代表 UE 内置能力。
- Kubernetes、Agones、Amazon GameLift Servers 和 OpenTelemetry 链接均指向供应商/项目官方文档。
- 代码块中的 `<...>` 是占位符；带“适配伪代码”标注的示例不能直接当作第三方 SDK 调用。
