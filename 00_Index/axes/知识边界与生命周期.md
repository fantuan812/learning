# 知识边界与生命周期

> 知识成熟度：L2（路由规则已与现有 taxonomy、Canonical 和工作流边界核对）。

本规则决定材料放置位置：先判生命周期，再判知识与项目边界。置信度低于 0.75 的结构动作只进入 [Inbox](../../Inbox/README.md) 或 [review queue](../../.kb/review-queue.md)，不直接移动正文。

## 四类路由

| 类别 | 判定 | 首选位置 | 处理原则 |
| --- | --- | --- | --- |
| universal | 与具体项目、仓库、账号、部署环境无关，可迁移复用 | 现有六大领域；分类决策确认独立新领域后才扩展 [Knowledge](../../Knowledge/README.md) | 一个概念一个 Canonical，未确定归属的材料留在 Inbox |
| project | 依赖明确项目名、代码路径、配置、线上环境或业务约束 | [Projects](../../Projects/README.md) 下的明确项目目录 | 未确认项目身份不得创建子目录；项目实现与通用原理分开 |
| mixed | 同时含通用原理和项目实现或证据 | 可独立复用的原理进入领域 Canonical；项目细节进入明确项目；跨域叙事可留在 [系统实战](../../系统实战/README.md) | 按叙事边界选择保留加互链或有完整性证据的拆分，不复制全文 |
| temporary | 日期日志、随手笔记、原始对话、未分类材料或删除候选 | [工作日志](../../工作日志/README.md)、[笔记](../../笔记/README.md)、[Inbox](../../Inbox/README.md)、[Archive](../../Archive/README.md) | 保留时间上下文，不能直接作为 Canonical |

六大领域入口：[计算机基础](../domains/计算机与工程基础.md)、[游戏知识](../domains/游戏知识.md)、[游戏服务端](../domains/游戏服务端.md)、[游戏算法](../domains/游戏算法.md)、[游戏 AI](../domains/游戏AI.md)、[测试与质量](../domains/游戏测试与质量.md)。

## 边界目录

- [Knowledge](../../Knowledge/README.md)：无既有领域归属的通用知识骨架，不是六大领域的机械搬迁目标。
- [Projects](../../Projects/README.md)：仅在项目身份明确且预计至少有 3 个相关单元或持续增长时创建子目录。
- [evidence](../../evidence/README.md)：实验源代码、测试、原始结果和复现步骤；它支撑正文，但不替代正文。
- [工作日志](../../工作日志/README.md)：按日期保存过程证据和决策上下文；提炼结论时保留原日志链接。
- [笔记](../../笔记/README.md)：个人速查和短材料；查重、补证据和扩写后才可提升为 Canonical。
- [Inbox](../../Inbox/README.md)：所有未分类新材料的统一入口。
- [Archive](../../Archive/README.md)：历史原材料和删除候选，默认不作为知识入口。
- [方案](../../方案/README.md)：仓库建设计划和控制面，不属于知识正文。
- [读书笔记](../../读书笔记/README.md)：来源集合，保留书目与章节上下文；不自动判为 temporary。可提炼的概念关联已有领域主文，来源层按著作组织不等于按著作建立主题分类。

## 提升流程

`Inbox / 笔记 / 工作日志` → 区分事实、推断与建议 → 查重与别名 → 判定四类 → 选择唯一 Canonical → 补标准 Markdown 与 OKF 元数据 → 链接 Evidence → 更新 MOC 与 manifest → 运行 `check_okf Changed` 和 `check_repo`。

- temporary 提升时必须保留原材料链接。
- mixed 提升时先检查通用部分是否独立、拆分是否损伤链路叙事，再决定拆分或保留加链接。
- Evidence 只有实际执行并保存原始输出后，才可支持对应的高成熟度声明。

## 禁止事项

- 不按来源名、日期或工具名建立主题主分类；来源集合可以保留书目、日期与工具上下文。
- 不因关键词“项目”“业务”“真实项目”自动判为 project。
- 不复制第二份 Canonical 正文。
- 不在链接影响尚未审计时批量改路径。
