## 学习路径

1. 数学地基：`02-数学与碰撞/01-向量与矩阵基础` → `02-数学与碰撞/02-四元数与旋转`
2. 寻路主线：`01-寻路与图论/01-图论基础与搜索算法` → `01-寻路与图论/02-A星算法与优化`
3. 工程实战：`03-工程与实用技巧` 各篇（随机、生成、AOI、平滑）
4. P1 工程闭环：04-确定性与基准工程/01-动态寻路确定性与基准测试；先掌握增量重规划与 NavMesh，再接入确定性、回放和基准阈值。
