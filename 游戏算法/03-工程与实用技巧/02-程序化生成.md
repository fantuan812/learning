## 1. 概述

程序化生成的本质是"**用可复现的随机 + 规则**制造内容"：

- **可复现**：在算法版本、配置、哈希、浮点实现和遍历顺序一致时，同一世界种子 + 同一坐标才应生成同一结果（联机一致、存档可恢复）；
- **分层**：高度图 → 气候 → 生物群系 → 物件，每层都是上一层的函数；
- **可调**：参数（频率、倍频、阈值）集中配置，策划可以"调地形"而不是"画地形"。

典型应用：Roguelike 地牢（以撒、杀戮尖塔）、开放世界地形（Minecraft、戴森球）、星系生成（无人深空）、关卡布局（死亡细胞）。

```mermaid

```

## 3. 噪声：Perlin 与 Simplex

### 3.1 值噪声 vs 梯度噪声

**值噪声**：在整数格点上放随机值，中间插值——容易产生"块状感"，频率响应不平滑。
**梯度噪声**：格点上放**随机梯度向量**，采样点取其与格点的点积再插值——一阶连续、各向同性更好，Perlin 噪声就是梯度噪声。

### 3.2 Perlin 噪声原理（2D）

1. 把采样点 `(x, y)` 映射到所在整数格 `(i, j)` 及格内偏移 `(u, v)`；
2. 从**置换表 perm**（256 个值翻倍成 512，保证环绕性）查 4 个格点的梯度；
3. 计算 4 个方向点积：`dot(g00, (u, v))`、`dot(g10, (u−1, v))`、`dot(g01, (u, v−1))`、`dot(g11, (u−1, v−1))`；
4. 用 **fade 函数**平滑插值（Perlin 2002 改进版）：

```
fade(t) = 6t^5 − 15t^4 + 10t^3
```

fade 保证在 t = 0 和 t = 1 处一阶、二阶导数均为 0，插值结果 C2 连续。

```cpp
// 简化 2D Perlin 核心（假设 perm[512] 已由种子打乱生成）
float fade(float t) { return t * t * t * (t * (t * 6.f - 15.f) + 10.f); }

float grad(int h, float x, float y) {
    // 由哈希 h 的低位选 8 个方向之一，返回方向向量与 (x,y) 的点积
    switch (h & 7) {
        case 0: return  x + y;
        case 1: return -x + y;
        case 2: return  x - y;
        case 3: return -x - y;
        case 4: return  x;
        case 5: return -x;
        case 6: return  y;
        default: return -y;
    }
}

float perlin2D(float x, float y, const int perm[512]) {
    int xi = (int)floorf(x) & 255, yi = (int)floorf(y) & 255;
    float xf = x - floorf(x), yf = y - floorf(y);
    float u = fade(xf), v = fade(yf);
    int aa = perm[perm[xi]     + yi];
    int ab = perm[perm[xi]     + yi + 1];
    int ba = perm[perm[xi + 1] + yi];
    int bb = perm[perm[xi + 1] + yi + 1];
    float x1 = lerp(grad(aa, xf, yf),     grad(ba, xf - 1, yf),     u);
    float x2 = lerp(grad(ab, xf, yf - 1), grad(bb, xf - 1, yf - 1), u);
    return lerp(x1, x2, v);   // 输出约 [-1, 1]
}
```

### 3.3 Simplex 噪声

Simplex 噪声（Ken Perlin, 2001）把正方形/立方体晶格换成**单形（simplex，2D 是三角形）**：

- **偏斜变换**：2D 中把方形坐标 `(x, y)` 映射到斜坐标：`F = (√3 − 1)/2`，`s = (x + y)·F`，`x' = x + s, y' = y + s`；反变换系数 `G = (3 − √3)/6`；
- **选单形**：按斜坐标的整数部分判断点落在两个三角形中的哪一个；
- **径向衰减**：`max(0, r² − |d|²)⁴ · dot(g, d)`，其中 r² 固定（0.5 或 0.6），衰减到 0 即无需插值权重归一。

优点：计算量随维度增长更慢（3D/4D 优势明显）、**无方向性伪影**、梯度更丰富。注意：Simplex 的原始专利已于 2022 年 1 月到期，现已可自由使用；工程上多数引擎（Unity 的 Mathf.PerlinNoise 是 Perlin，Godot 的 FastNoiseLite 含 Simplex）两者都提供。

### 3.4 fBm：分形叠加与域扭曲

单层噪声太平滑，真实地形有"大轮廓 + 中起伏 + 小细节"的多尺度结构——用**分形布朗运动（fBm）**叠加：

```
fbm(x) = Σ_{o=0}^{oct−1} amplitude_o · noise(frequency_o · x)
amplitude_o = persistence^o        （默认 persistence = 0.5）
frequency_o = lacunarity^o         （默认 lacunarity = 2.0）
```

```cpp
float fbm(float x, float y, int octaves,
          float lacunarity = 2.f, float gain = 0.5f,
          const int perm[512]) {
    float amp = 1.f, freq = 1.f, sum = 0.f, norm = 0.f;
    for (int o = 0; o < octaves; ++o) {
        sum  += amp * perlin2D(x * freq, y * freq, perm);
        norm += amp;
        amp  *= gain;
        freq *= lacunarity;
    }
    return sum / norm;   // 归一化回 [-1, 1]
}
```

**域扭曲**：采样前用另一层噪声扭曲坐标，产生流云、岩浆、侵蚀感：

```
warped(x, y) = fbm( x + a·fbm(x, y), y + b·fbm(x + 5.2, y + 1.3) )
```

### 3.5 应用：高度图

```
height = base + 大陆轮廓(低频 fbm) * 0.6
                + 山脉(中频 fbm + 域扭曲) * 0.3
                + 细节(高频 fbm) * 0.1
```

再按阈值切分：`< 0.25` 海洋、`< 0.35` 沙滩、`< 0.65` 平原、`< 0.85` 丘陵、其余山地；用 `abs(noise) ^ k` 可制造尖锐山脊（红警/塞尔达风）。**高度图缓存为纹理/数组**，供后续管线复用，避免每帧重算。

## 4. Voronoi 图

### 4.1 定义与对偶

给定平面上一组种子点 `{s_i}`，Voronoi 单元是把每个点划给**最近种子**的区域：

```
V(s_i) = { p ∈ R² : |p − s_i| ≤ |p − s_j|, ∀ j }
```

- 相邻单元边界是种子连线的**垂直平分线**；
- 对偶图是 **Delaunay 三角剖分**（最大化最小角的三角化，也是泰森多边形）；
- 精确生成用 Fortune 扫描线 O(n log n)；游戏里常用**网格近似**：对每个像素/瓦片计算最近种子点，O(像素 × 种子数)，易并行（GPU/多线程）。

### 4.2 变体与应用

| 变体 | 做法 | 游戏用途 |
| --- | --- | --- |
| 标准 Voronoi | 欧氏距离 | 领土划分、星系恒星系 |
| 曼哈顿/切比雪夫距离 | 换距离度量 | 地牢房间分区、城市街区 |
| 松弛 Voronoi（Lloyd） | 迭代把种子移到单元质心 | 更均匀的"细胞"排布（关卡房间） |
| 噪声扰动边界 | 单元距离函数 `f(p) = d1 − d2` 加噪声 | 生物群系地图（泰拉瑞亚式） |
| 距边距离 `|d1 − d2|` | 两近邻距离差 | 大陆板块边缘、山脉脊线 |

```python
import math, random

def voronoi_cells(w, h, sites):
    """网格近似：返回每个像素所属站点索引（O(w*h*|sites|)）"""
    grid = [[0] * w for _ in range(h)]
    for y in range(h):
        for x in range(w):
            best, bd = 0, float("inf")
            for i, (sx, sy) in enumerate(sites):
                d = (x - sx) ** 2 + (y - sy) ** 2
                if d < bd:
                    bd, best = d, i
            grid[y][x] = best
    return grid
```

## 5. 迷宫生成

### 5.1 完美迷宫

把网格的墙按规则打通，使任意两格**恰好一条路径**（生成树）。三种主流算法：

| 算法 | 思路 | 时间复杂度 | 风格特点 |
| --- | --- | --- | --- |
| 递归回溯（DFS） | 深度优先随机走，死路回溯 | O(V+E) | 长走廊、少分叉，适合地牢主路 |
| 随机 Prim | 从边界集合随机扩展 | O(E log E) 或 O(E) | 分支多、树形均衡，像天然洞穴网 |
| 随机 Kruskal | 随机打乱墙，并查集判环 | O(E log E) | 各向均匀，接近均匀生成树 |

### 5.2 递归回溯（Randomized DFS）

```
stack ← [起点]; 标记起点已访问
while stack 非空:
    cur ← stack 顶
    neighbors ← cur 的未访问相邻格
    if neighbors 为空:
        stack.pop()                # 死路回溯
    else:
        n ← neighbors 中随机一个
        打通 cur 与 n 之间的墙
        标记 n 已访问; stack.push(n)
```

```python
import random

def maze_recursive_backtracker(w, h):
    # 每个格子的墙: N/E/S/W 布尔; visited 标记
    visited = [[False] * w for _ in range(h)]
    walls = [[[True]*4 for _ in range(w)] for _ in range(h)]
    stack = [(0, 0)]
    visited[0][0] = True
    dirs = [(-1,0,0,2),(1,0,2,0),(0,-1,3,1),(0,1,1,3)]  # (dy,dx,墙位,对面墙位)
    while stack:
        y, x = stack[-1]
        cand = []
        for dy, dx, w1, w2 in dirs:
            ny, nx = y + dy, x + dx
            if 0 <= ny < h and 0 <= nx < w and not visited[ny][nx]:
                cand.append((ny, nx, w1, w2))
        if not cand:
            stack.pop()
        else:
            ny, nx, w1, w2 = random.choice(cand)
            walls[y][x][w1] = False          # 打通当前格的墙
            walls[ny][nx][w2] = False        # 打通邻居的墙
            visited[ny][nx] = True
            stack.append((ny, nx))
    return walls
```

### 5.3 随机 Prim 与随机 Kruskal

**随机 Prim**：维护"已访问格子的边界墙"集合，每次随机取一条墙打通，把墙另一侧未访问的格子加入边界。优先队列实现 O(E log E)；用"边界列表 + 随机交换删除"可做到均摊 O(1) 取随机。

**随机 Kruskal**：

```
edges ← 所有相邻格之间的墙，随机打乱
uf ← 每个格子一个集合（并查集）
for e in edges:
    if find(e.u) != find(e.v):
        union(e.u, e.v); 移除墙 e      # 加边不成环
```

并查集带路径压缩后单次近 O(α)，总体 O(E log E)（排序主导）。**应用**：递归回溯适合"主城地牢"（路线线性推进），Prim 适合洞穴系（分支多），Kruskal 适合需要统计均匀性的场合；还有 Wilson 算法（随机游走 + 擦圈）能生成**均匀随机生成树**，但常数大，通常用不到。

## 6. 波函数坍缩（WFC）

### 6.1 思想

WFC（Maxim Gumin, 2016）把关卡生成建模为**约束满足问题**：每个格子有一个"可能瓦片"的**叠加态**；不断重复"选熵最小的格子 → 随机坍缩为一个瓦片 → 向邻居传播约束"，直到全部确定。规则只描述**局部**（相邻瓦片兼容表），却能涌现出整体一致的布局（路径贯通、建筑结构合理）。

### 6.2 邻接规则

瓦片兼容用方向规则表描述，例如：

| 瓦片 | 上 | 下 | 左 | 右 |
| --- | --- | --- | --- | --- |
| 草地 | 草地/道路 | 草地/道路 | 草地/道路 | 草地/道路 |
| 道路 | 草地/道路 | 草地/道路 | 道路 | 道路 |
| 水 | 水/沙滩 | 水/沙滩 | 水/沙滩 | 水/沙滩 |
| 沙滩 | 水/沙滩/草地 | 水/沙滩/草地 | 水/沙滩/草地 | 水/沙滩/草地 |

也可用"重叠模型"：从示例图里统计所有 k×k 切片的相邻关系，自动生成规则。

### 6.3 算法流程

```
cells ← 所有格子初始化为全部瓦片的叠加态
while 存在未坍缩格子:
    c ← 熵最小的格子（H = −Σ p·log p，或用候选数简化）
    collapse(c): 按权重随机选一个瓦片，其余可能性移除
    propagate(c): BFS 队列传播约束
        对每个受影响邻居:
            移除与当前格已确定/可能瓦片不兼容的候选
            若某格候选集为空 → 冲突（矛盾）
    冲突处理: 回溯（栈记录坍缩历史）或整体重试（换种子）
```

```python
import random
from collections import deque

def wfc(w, h, tile_names, adj, weights):
    """adj: (tile -> 方向 -> 兼容tile集合)；返回瓦片矩阵或 None"""
    all_tiles = set(tile_names)
    grid = [[set(all_tiles) for _ in range(w)] for _ in range(h)]

    def propagate(q):
        while q:
            x, y = q.popleft()
            for dx, dy, d in [(0,1,"D"),(0,-1,"U"),(1,0,"R"),(-1,0,"L")]:
                nx, ny = x + dx, y + dy
                if not (0 <= nx < w and 0 <= ny < h):
                    continue
                allowed = set()
                for t in grid[y][x]:
                    allowed |= adj[t][d]
                if not (grid[ny][nx] <= allowed):
                    grid[ny][nx] &= allowed
                    if not grid[ny][nx]:
                        return False          # 冲突
                    q.append((nx, ny))
        return True

    for _ in range(w * h):
        cands = [(x, y) for y in range(h) for x in range(w)
                 if len(grid[y][x]) > 1]
        if not cands:
            return [[next(iter(grid[y][x])) for x in range(w)] for y in range(h)]
        x, y = min(cands, key=lambda p: len(grid[p[1]][p[0]]))  # 最小熵
        chosen = random.choices(sorted(grid[y][x]),
                                weights=[weights[t] for t in sorted(grid[y][x])])[0]
        grid[y][x] = {chosen}
        if not propagate(deque([(x, y)])):
            return None   # 冲突：换种子重试
    return [[next(iter(grid[y][x])) for x in range(w)] for y in range(h)]
```

### 6.4 工程要点

- **失败处理**：WFC 可能矛盾（尤其手写规则不全时）。标准做法是带回溯的深度搜索；工程上更常用"整体重试 N 次 + 种子枚举"，因为规则质量高时成功率 > 95%；
- **熵启发**：候选数少的格子优先坍缩（最"确定"的先定），能显著降低冲突率；
- **性能**：朴素实现每步扫描全图 O(cells)，可用优先队列按熵维护；传播用 BFS 只动受影响区域；
- **规模**：单张地图（如 100×100）毫秒级；超大世界用"分块 WFC + 边界约束"保证块间衔接。

## 7. 地形与地图生成管线

### 7.1 完整管线

```mermaid
flowchart LR
    A["世界种子"] --> B["Chunk 分块 + 哈希种子"]
    B --> C["高度图: fBm + 域扭曲"]
    C --> D["侵蚀模拟（河流/山脊）"]
    D --> E["湿度图 + 温度图（按纬度）"]
    E --> F["生物群系分类"]
    F --> G["水体/道路/物件放置"]
    G --> H["网格化 + LOD 渲染"]
    H --> I["存档: 保存种子与玩家改动"]
```

**分层细节**：

1. **大陆层**：低频 fBm 或 Voronoi 板块 → 大陆/海洋轮廓；
2. **起伏层**：中频 fBm + 域扭曲 → 山脉、盆地；`|noise|^k` 出山脊；
3. **侵蚀层**：水力侵蚀（水滴模拟：水滴下落带走沉积物，迭代几百~几千次）让河谷更真实；预算不足时用"噪声减法"近似（`height − 河流噪声`）；
4. **气候层**：湿度 = 距海距离 + 降雨噪声；温度 = 纬度 + 海拔衰减；两者查表得生物群系：

| 海拔 \ 湿度 | 低湿 | 中湿 | 高湿 |
| --- | --- | --- | --- |
| 低 | 草原 | 森林 | 沼泽 |
| 中 | 丘陵草原 | 温带森林 | 雨林 |
| 高 | 荒漠山地 | 山地 | 雪峰 |

5. **物件层**：按生物群系密度表撒树/石/草（用块种子 RNG，见 01 篇）；道路用寻路或流场连接聚落；
6. **无限世界**：Chunk 尺寸 32~128 格；`seed = hash(worldSeed, cx, cy)`；按玩家位置异步生成、LRU 卸载。

### 7.2 性能与确定性

- 生成与渲染分离：后台线程逐块生成，完成后推给渲染线程（注意数据竞争，用完成队列）；
- 高度图降采样 LOD：远处用低分辨率噪声直接算，近处用缓存纹理；
- 确定性要求：**生成代码里禁止用时间/地址做种子、禁止依赖浮点平台差异**（见 01 篇 4.2）；
- 玩家改动（挖矿、建造）与程序化基座分层存储：`base = generate(seed)` 只读，`delta = 玩家修改` 写存档。

## 8. 复杂度分析

| 算法 | 时间复杂度 | 空间复杂度 | 说明 |
| --- | --- | --- | --- |
| Perlin 2D 单点 | O(1) | O(512) | 置换表 |
| Simplex 2D/3D 单点 | O(1) | O(512) | 高维更优 |
| fBm（o 个倍频） | O(o) | O(1) | 每倍频一次噪声 |
| 域扭曲 | O(o) | O(1) | 约 2× fBm 成本 |
| Voronoi 网格近似 | O(W·H·S) | O(S) | 可并行/GPU |
| Fortune 扫描线 | O(n log n) | O(n) | 精确 Voronoi |
| 递归回溯迷宫 | O(V+E) | O(V) | 栈深 = 最长走廊 |
| 随机 Prim 迷宫 | O(E log E) | O(E) | 堆优化 |
| 随机 Kruskal 迷宫 | O(E log E) | O(V) | 并查集 |
| WFC 单次坍缩+传播 | O(受影响格 × 候选 × 邻接) | O(格 × 候选) | 最坏指数，实际近线性 |
| 水力侵蚀（n 水滴） | O(n × 步长) | O(1) | 离线条目可调 |

## 验证与基准建议

- 输入规模与边界用例：覆盖 1×1/空地图、最小和超大分块、固定种子与随机种子、边界坐标、不同频率/倍频、迷宫起终点、WFC 无解规则和回溯上限；先用 8×8 小图，再扩展到目标分辨率。
- 正确性断言：固定输入应生成相同哈希或金样；迷宫应满足连通性/无非法墙穿越，WFC 输出应满足邻接规则，地形采样应满足范围和边界连续性；失败时记录种子、规则版本和首个冲突。
- 复杂度与耗时指标：记录输出分辨率、分块数、噪声层数、候选/回溯次数、内存峰值、单块 P50/P95 耗时和 WFC 成功率；不同机器的性能数字只作为各自实测结果。
- 命令示意（仅示意，不表示仓库已有测试）：`python -m pytest tests/test_procgen.py -q`；C++/工具链可用项目自有测试导出金样并做基准。

## 9. 最佳实践

1. **一切从种子出发**：提供"种子 = 0 的黄金种子集"用于自动化测试与直播演示；版本升级导致生成变化时保留旧版本生成器（存档兼容）。
2. **噪声参数配置化**：倍频、lacunarity、persistence、阈值全部进配置表，策划可调；参数命名与美术直觉对齐（"山脊度""河流密度"）。
3. **分层叠加，单层可关**：管线每层可独立开关与调试（高度图调试视图、群系调试视图）。
4. **异步分块生成**：永远不要在渲染线程同步生成大块；用固定预算（每帧 N 块）分摊。
5. **种子回归测试**：CI 用固定种子渲染/导出金样（golden sample），任何算法改动先比对差异。
6. **WFC 规则先小图验证**：规则表用 8×8 小图跑 1000 次统计成功率，再上大图。
7. **内存预算**：高度图/迷雾等大数组用位图或 uint16 压缩（见 05 篇），避免 float 全量。

## 10. 常见问题 FAQ

**Q1：Perlin 噪声为什么有明显的"格点感/对角线伪影"？**
2D Perlin 的方形晶格在特定频率下会露出网格痕迹。对策：用 Simplex、提高倍频数、叠加域扭曲，或让频率避开整数格对齐。

**Q2：Simplex 噪声能商用吗？**
原始专利（US 6867774，2001 年申请）已于 2022 年 1 月到期；OpenSimplex/开源实现亦普遍可用。商用前确认所选实现的授权条款即可。

**Q3：WFC 频繁失败怎么办？**
优先检查邻接规则是否完备（每对瓦片四个方向都要定义）；其次用"熵最小优先 + 回溯"；最后允许"降级填充"（冲突格放默认瓦片并打日志）。

**Q4：迷宫生成结果"总是一个方向"？**
递归回溯天然偏向长走廊；若需要均匀分支用 Kruskal/Prim；需要统计均匀（所有生成树等概率）用 Wilson 算法。

**Q5：无限世界怎么保证所有客户端生成一致？**
只用"世界种子 + 坐标哈希"驱动，禁止时间/平台相关输入；浮点仅用于高度计算，判定用整数坐标；版本号写进存档。

**Q6：运行时生成太卡怎么办？**
分帧预算 + 异步线程 + 预生成（进图前生成周边 3×3 块）+ LOD 降采样；终极方案是离线烘焙 + 增量加载。

**Q7：玩家改造后的地形怎么和程序化基座共存？**
分层存储：基座 = f(seed) 只读；修改 = delta 表（chunk、坐标、新值），加载时叠加。这样升级生成算法不丢玩家改动。
