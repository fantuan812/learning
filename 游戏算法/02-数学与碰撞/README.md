# 02 · 数学与碰撞（Mathematics & Collision）

> 知识成熟度：L2（已按 6 篇核心专题、物理碰撞几何管线与运动学模拟全面核对）。
>
> 领域权威导航：[游戏算法 Domain MOC](../../00_Index/domains/游戏算法.md) ｜ [游戏算法 领域工程手册](../README.md)。

「数学与碰撞」是游戏算法知识库中最基础、也最通用的几何物理分类。游戏引擎中的一切运动与交互都可以抽象为**位置（Position）、朝向（Orientation）、速度（Velocity）与接触（Contact）**四个核心要素，其背后的数学载体与算法机制正是本子域所沉淀的全部内容：

- **向量与变换矩阵**：空间坐标变换、点积/叉积几何投影，是角色朝向、视野判定与相机管线的数学地基；
- **四元数代数**：彻底根除欧拉角万向锁（Gimbal Lock），提供最短弧度插值（Slerp），驱动骨骼动画与刚体旋转；
- **插值与样条曲线**：Lerp/Slerp、贝塞尔与 Catmull-Rom 样条，赋能角色位移、运镜平滑与网络预测外推；
- **碰撞检测几何学**：基础图元相交、SAT 分离轴测试、凸体相交 GJK 与穿透深度 EPA，构建 Narrow-phase 接触求解；
- **数值积分动力学**：剖析显式欧拉发散缺陷，证明半隐式欧拉保相守恒性，详解 Verlet 约束与 RK4 高精度求解；
- **弹道物理与射击算法**：抛物线落点逆向解算、目标移动提前量解算、高斯散布采样与高速连续碰撞（CCD）扫掠。

## 3. 核心算法横向选型指南

### 3.1 窄相碰撞算法选型（Narrow-phase）
- **简单包围盒（AABB / Sphere / Capsule）**：计算成本极低（单次两两检测仅需数个乘加），用于海量实体的大致相交测试或粗粒度过滤；
- **定向包围盒（OBB）**：使用 **SAT（分离轴定理）** 测试 15 条可能轴（3条面法线 + 3条面法线 + 9条边叉积轴），旋转适应好，常用于车辆、建筑与精密掩体；
- **任意凸多面体（Convex Polyhedra）**：使用 **GJK 算法** 在闵可夫斯基差空间通过单形（Simplex）演化测试是否包含原点；相交后若需要接触法线与穿透深度，由 **EPA 算法** 从 GJK 最终单形向外拓展求最近面。

### 3.2 动力学数值积分选型（Integrators）
- **半隐式欧拉（Symplectic Euler）**：游戏物理引擎事实标准（Box2D/PhysX/Chaos）。由于其保相体积（Phase Space Volume Preserving）特性，简谐振动能量有界不发散，且单步只需 1 次受力估算；
- **Verlet / Position-Based Dynamics (XPBD)**：位置约束直观，不依赖速度累积，广泛用于布料、绳索、毛发与角色次级动态；
- **四阶龙格-库塔（RK4）**：每步需 4 次评估导数，耗时较高；仅适用于航天器轨道计算、高保真飞行力学等连续非碰撞场景。

## 4. 学习顺序建议

```mermaid
flowchart LR
    A["01 向量与矩阵基础<br/>空间变换地基"] --> B["02 四元数与旋转<br/>稳定角位移"]
    A --> C["03 插值与曲线<br/>平滑运动与过渡"]
    B --> D["04 碰撞检测<br/>几何相交与接触"]
    C --> D
    A & B --> E["05 数值积分与动力学<br/>欧拉/Verlet物理仿真"]
    D & E --> F["06 弹道与射击算法<br/>提前量/散布/CCD扫掠"]
```

### 推荐学习步骤
1. **第一阶段：数学地基（01、02、03 篇）**
   - 掌握点积余弦公式判夹角、叉积右手定则判左右与旋转轴；
   - 手动推导四元数共轭、乘法与 Slerp 半角插值；
   - 实现 Catmull-Rom 样条路径与平滑 Ease 缓动。
2. **第二阶段：几何与碰撞（04 篇）**
   - 实现 AABB 相交与 SAT 分离轴测试；
   - 理解闵可夫斯基差几何意义与 GJK 单形求交逻辑。
3. **第三阶段：运动动力学与战斗射击（05、06 篇）**
   - 对比显式欧拉与半隐式欧拉在简谐振子下的能量曲线；
   - 求解带重力弹道在指定初速度下的仰角封闭方程；
   - 求解目标匀速直线运动下的前瞻提前量（Lead Point）；
   - 搭建高速子弹 Raycast 与 Sphere Cast 连续碰撞检测（CCD）。
