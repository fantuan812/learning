# 模板目录

`OKF-知识条目.md` 是本仓库的标准入口。Obsidian 的 Templates folder location 应设置为 `references/templates`；插入后填写 `description`、`tags`、`sources`，并按证据情况更新 `verified`。

> 知识成熟度：L2。本模板说明已通过静态校验并具备可执行验证，字段约定随 OKF profile 演进复查。
