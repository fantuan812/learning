# 数学与算法基础总览
> 验证与基准：按文中命令执行最小实验，记录结果与边界。

> 知识成熟度：L2（定义、推导与边界已核对；数值稳定性需目标平台复测）。
> 知识基线：离散数学、概率统计、线性代数、数值分析与算法复杂度。
> 最后更新：2026-08-20。
> 官方参考：[NIST DLMF](https://dlmf.nist.gov/)、[MIT OpenCourseWare](https://ocw.mit.edu/)。
> 验证入口：按文中例题、性质测试和数值误差实验复核。

本文是工程师可执行的数学地图。目标不是背公式，而是知道模型的假设、推导、误差来源和适用边界。

## 1. 离散数学

### 1.1 集合与函数

- 集合运算：并、交、差、补、笛卡尔积。
- 函数的定义域、值域、单射、满射和双射。
- 计算机中的类型集合可以视为有限集合；溢出意味着模型映射不再保持预期性质。
- 幂集大小为 `2^n`，因此位掩码天然表示子集。

### 1.2 命题逻辑

- 命题、合取、析取、蕴含、等价和否定。
- `P -> Q` 等价于 `!P || Q`；排查条件分支时应先写真值表。
- 德摩根律：`!(P && Q) = !P || !Q`，`!(P || Q) = !P && !Q`。
- 归纳证明适合递归算法、循环不变量和数据结构不变式。

### 1.3 谓词与量词

- 全称量词描述所有输入，存在量词描述至少一个见证。
- 量词顺序不可交换：`∀x∃y` 通常不等于 `∃y∀x`。
- 测试设计应覆盖前置条件、后置条件以及反例。

### 1.4 关系与偏序

- 自反、对称、反对称、传递是常见性质。
- 等价关系划分集合；偏序关系产生拓扑排序和依赖图。
- 编译依赖、任务调度、资源获取顺序都可建模为偏序。

### 1.5 图论

- 图由顶点和边组成，可有向、无向、带权、多重或含环。
- 度、路径、连通分量、割点、桥和强连通分量是诊断网络与依赖的基础。
- BFS 求无权最短路；Dijkstra 要求非负边权；Bellman-Ford 可处理负权。
- DAG 支持拓扑排序；关键路径是最长路径动态规划。
- 最小生成树常用 Kruskal 或 Prim；并查集维护连通分量。
- 二分图可用于匹配、排班和资源分配。

### 1.6 树与递归

- 树有 `n-1` 条边且任意两点唯一简单路径。
- 二叉搜索树的有序性依赖比较关系和旋转不变式。
- 堆保证局部序，不保证全局有序；适合优先队列。
- 递归证明要给出基例、归纳假设和归纳步骤。

### 1.7 组合计数

- 加法原则处理互斥选择，乘法原则处理独立阶段。
- 排列 `P(n,k)` 与组合 `C(n,k)` 的差异是是否考虑顺序。
- 鸽巢原理常用于哈希冲突和容量下界证明。
- 容斥原理处理重叠集合，但项数可能指数增长。
- 生成函数可把计数递推转化为多项式运算。

### 1.8 递推与证明

- 等差、等比递推可直接求解；分治递推可用主定理估算。
- `T(n)=2T(n/2)+O(n)` 为 `O(n log n)`。
- 摊还分析关注一系列操作的平均成本，不等同于概率平均。
- 势能法为动态数组扩容、并查集等结构建立整体成本上界。

## 2. 概率与统计

### 2.1 概率公理

- 概率在 `[0,1]`，全集概率为 1，互斥事件概率可相加。
- 条件概率 `P(A|B)=P(A∩B)/P(B)`，前提是 `P(B)>0`。
- 独立性意味着 `P(A∩B)=P(A)P(B)`，不等同于“不相关”。

### 2.2 贝叶斯与全概率

- 全概率：`P(A)=Σ P(A|Bi)P(Bi)`。
- 贝叶斯：`P(H|E)=P(E|H)P(H)/P(E)`。
- 监控告警需要区分先验故障率和检测器误报率。

### 2.3 随机变量

- 离散变量用概率质量函数，连续变量用密度函数。
- 期望是线性的，即使变量不独立也成立。
- 方差衡量波动：`Var(X)=E[X²]-E[X]²`。
- 协方差和相关系数描述线性联动，不代表因果。

### 2.4 常见分布

- Bernoulli：一次成功/失败。
- Binomial：固定次数独立试验中的成功数。
- Geometric：首次成功所需次数。
- Poisson：固定窗口内稀有事件计数。
- Exponential：连续等待时间，具有无记忆性。
- Normal：大量小扰动叠加后的近似模型。
- Heavy-tail 分布提醒我们均值可能掩盖长尾风险。

### 2.5 极限定理与抽样

- 大数定律说明样本均值趋近总体均值。
- 中心极限定理说明在一定条件下均值近似正态。
- 独立同分布、有限方差等假设必须写清楚。
- Bootstrap 可通过重采样估计不确定性。

### 2.6 统计推断

- 点估计给出参数单值，区间估计给出不确定性范围。
- 置信区间不是“参数落入区间的概率”，而是重复抽样覆盖率的陈述。
- 假设检验要报告效应量、样本量和实际意义，不只看 p 值。
- 多重比较会提高假阳性，需要校正或预注册指标。

### 2.7 工程中的随机性

- 随机测试、负载到达、丢包、缓存命中都应记录种子和分布。
- P50、P95、P99 是分位数，长尾系统不应只看平均值。
- 排队系统中利用率接近 1 时等待时间会非线性增长。
- 模拟实验应做重复运行、置信区间和敏感性分析。

## 3. 线性代数与几何

### 3.1 向量与矩阵

- 向量表示状态、位置、特征或资源计数。
- 矩阵表示线性变换、方程组或图邻接关系。
- 乘法维度必须匹配；实现中应明确行主序/列主序。
- 稀疏矩阵只存非零项，适合大规模图和约束系统。

### 3.2 内积与范数

- 点积衡量投影和相似度；叉积在三维中给出法向量方向。
- `L1` 范数鼓励稀疏，`L2` 范数平滑大误差，`L∞` 关注最大误差。
- 归一化前要处理零向量和浮点误差。

### 3.3 线性方程组

- 高斯消元、LU 分解用于求解 `Ax=b`。
- 条件数高意味着小输入误差可能放大为大输出误差。
- 不要显式求逆来解方程；优先使用分解和稳定求解器。

### 3.4 特征值与分解

- 特征值揭示变换的伸缩方向；图拉普拉斯特征值反映连通性。
- QR、SVD 可用于最小二乘、降维和正交化。
- SVD 成本高，应考虑截断、随机化或稀疏方法。

### 3.5 几何与变换

- 齐次坐标统一平移、旋转、缩放为矩阵乘法。
- 变换组合顺序很重要；列向量约定下右侧乘法与左侧乘法含义不同。
- 四元数避免欧拉角万向节锁，但需处理归一化和符号等价。

## 4. 数值计算

### 4.1 误差分类

- 建模误差来自假设，截断误差来自近似，舍入误差来自有限精度。
- 绝对误差适合接近零的量，相对误差适合尺度比较。
- 误差预算应按关键路径和最终业务指标分配。

### 4.2 浮点数

- IEEE 754 包含符号、指数、尾数；不能精确表示多数十进制小数。
- 比较浮点数应使用绝对与相对容差，而不是 `==`。
- 大数加小数可能被吞掉；累加可用 Kahan 或分块求和。
- NaN 不等于自身，Infinity 需要显式处理。

### 4.3 稳定性

- 算法稳定性关注误差是否被放大；问题条件数是输入敏感度。
- 避免相近大数相减、指数溢出和病态矩阵直接求逆。
- 对数域计算可避免概率连乘下溢。

### 4.4 插值与积分

- 线性插值稳定简单；高阶多项式可能出现 Runge 振荡。
- 梯形、辛普森规则适用于不同平滑度和精度需求。
- 物理模拟中的辛积分器更好保持长期能量行为。

### 4.5 优化

- 梯度下降需要步长、停止条件和尺度归一化。
- 凸问题的局部最优即全局最优；非凸问题需关注初始化和鞍点。
- 约束优化可用拉格朗日乘子、投影梯度或二次规划。

## 5. 算法设计与复杂度

### 5.1 复杂度模型

- `O` 给出渐进上界，`Ω` 给出下界，`Θ` 给出紧界。
- 同一算法要区分最坏、平均、摊还和输入分布条件。
- 复杂度不仅是时间，也包括空间、带宽、同步和能耗。

### 5.2 设计范式

- 分治：拆分、递归求解、合并。
- 贪心：每步做局部选择，必须给出交换论证或拟阵条件。
- 动态规划：状态、转移、边界、遍历顺序和重建方案。
- 回溯：约束传播、剪枝、可行性判定。
- 随机化：随机快排、哈希、采样；记录随机种子便于复现。

### 5.3 正确性与测试

- 先写不变式，再写实现；每个优化都要保持不变式。
- 用性质测试验证交换律、幂等性、单调性等性质。
- 对极小、极大、空、重复、溢出和恶意输入做边界测试。
- Benchmark 要固定硬件、编译选项、数据集、预热和统计方法。

### 5.4 复杂度陷阱

- 隐式复制、字符串拼接、递归栈和哈希退化会改变复杂度。
- 并行化可能降低墙钟时间，却增加同步和内存带宽成本。
- 过早优化会破坏可验证性；先以剖析数据定位热点。

## 6. 工程速查表

| 问题 | 首选模型 | 常见误区 |
|---|---|---|
| 依赖执行顺序 | DAG/偏序 | 把环当作普通排序问题 |
| 无权最短路 | BFS | 用 DFS 期待最短 |
| 非负带权最短路 | Dijkstra | 忽略负权前提 |
| 事件到达 | Poisson/经验分布 | 只看平均到达率 |
| 向量相似度 | 点积/余弦 | 忽略零向量与归一化 |
| 解线性方程 | LU/QR | 显式求逆 |
| 浮点比较 | 容差 | 直接相等比较 |
| 性能结论 | 重复基准+分位数 | 单次运行下结论 |

## 7. 最低实践清单

- 能为一个递归或动态规划算法写出正确性证明。
- 能用图论表达依赖、路径和资源分配问题。
- 能解释均值、方差、分位数、置信区间和长尾。
- 能识别浮点误差、病态问题和数值不稳定操作。
- 能选择合适的范式并用复杂度和基准验证选择。

## 8. 进一步主题

- 信息论用熵、互信息和编码长度衡量不确定性与压缩极限。
- 图上的随机游走可用于排名、采样和故障传播建模。
- 马尔可夫链要求状态转移满足无后效性假设。
- 蒙特卡洛方法用大量样本估计难以解析求解的量。
- 重要性采样通过改变采样分布降低稀有事件估计方差。
- 排队论中的 Little 定律为 `L=λW`，可连接并发量、吞吐和延迟。
- 离散事件模拟应使用事件队列和可复现实验时钟。
- 信息论下界可用于判断压缩、排序和通信方案是否接近极限。
- 在线算法必须在不知道未来输入时做决策。
- 竞争比描述在线算法与最优离线算法的差距。
- 近似算法应同时报告误差界和适用输入条件。
- 参数化复杂度按参数规模分析问题的可处理性。
- 流式算法用有限内存处理大数据，需要明确误差概率。
- Bloom filter 允许假阳性但不允许假阴性，适合存在性预筛。
- Count-Min Sketch 估计频率时有单向偏差上界。
- 一致性哈希把节点变化造成的迁移量控制在合理范围。
- 哈希函数质量影响随机化算法的实际复杂度。
- 算法的空间局部性会影响缓存命中和实际性能。
- 向量化要求数据布局、对齐和尾部处理协同设计。
- 并行归约需要结合结合律；浮点加法非严格结合会造成结果漂移。
- 正确性证明应覆盖异常路径、取消路径和并发交错。
- 复杂度报告应注明输入编码长度，不能只写数值大小。
- 版本化基准防止编译器、硬件和数据变化造成误判。
- 实验记录参数、随机种子、环境、原始数据和分析脚本。
- 结论区分统计显著、工程显著和因果解释。
- 任何模型都要提供失效条件和监控指标。

## 9. 练习题方向

- 用归纳法证明二叉树节点数上界。
- 证明 BFS 首次访问节点得到无权最短距离。
- 构造一个 Dijkstra 不能处理的负权反例。
- 用贝叶斯公式计算告警后的真实故障概率。
- 比较均值、P95 和 P99 在长尾延迟中的差异。
- 实现稳定的向量归一化并测试零向量。
- 用 Kahan 求和比较普通累加的误差。
- 对病态矩阵构造输入扰动实验。
- 设计带剪枝的回溯搜索并统计节点数。
- 为动态规划写状态定义和边界证明。
- 使用 Bloom filter 测量假阳性率。
- 用 Little 定律核对服务的吞吐与并发观测。
- 重复运行随机算法并报告置信区间。
- 记录硬件、编译器和数据版本，复现一项基准。
- 对每个模型写出至少一个失效样例。

## 10. 记忆卡片

- 集合描述对象，函数描述映射。
- 逻辑不变量支撑正确性。
- 图表达关系，树表达层次。
- DAG 表达无环依赖。
- 组合数表达选择空间。
- 期望描述中心，方差描述波动。
- 独立不是不相关的同义词。
- 分位数比平均值更能描述长尾。
- 向量表达状态，矩阵表达变换。
- 条件数表达问题敏感度。
- 浮点数比较必须有容差。
- 稳定算法控制误差放大。
- 复杂度需写清输入模型。
- 摊还成本不是概率平均。
- 贪心需要正确性论证。
- 动态规划需要状态不变式。
- 随机算法需要种子和分布。
- 基准需要预热和重复。
- 记录原始数据便于复核。
- 误差结论必须说明假设。
- 复杂模型也要有简单基线。
- 先验证正确性，再优化性能。
- 让数学模型服务于工程决策。
