## 2. 概率模型与报告对象

### 2.1 定义先于样本量

随机变量表示观测结果；分布、期望和方差回答不同问题。条件概率要求条件事件有正概率；贝叶斯更新需要明确先验与似然。零相关一般不能推出独立，相关也不能推出因果。

对 iid、有限方差的观测，样本均值的方差为 `σ²/n`，标准误差为 `σ/√n`；常见中心极限定理还描述标准化均值的渐近分布。它不保证每次把 n 增大后绝对误差都下降。重尾、状态依赖、分布漂移或选择偏差不能由固定种子和大 n 自动消除。有限均值下的大数定律与有限方差下的上述误差率也不是同一个条件。

战斗统计至少区分：

| 问题 | 变量与单位 | 必须声明 |
| --- | --- | --- |
| 命中率 | 每次合资格攻击的 0/1 结果；概率无量纲 | 合资格规则、按攻击还是玩家统计、同玩家/同局依赖 |
| 平均伤害 | 每次攻击的伤害值；伤害单位 | 未命中是否记0，暴击率是条件于命中还是无条件，倍率与基础伤害 |
| 掉落成本 | 首次成功前成本或包含成功次的成本 | 保底重置、活动倍率、未成功的删失样本；不能默认 iid 几何模型 |
| 延迟尾部 | ms 或 s，窗口内的经验分位数 | 时间窗口、计时起止、超时/丢失样本、分位数定义与样本量 |

例如“命中概率 p、命中后暴击概率 c、基础伤害 d、暴击倍率 m”，在这个条件模型下，单次攻击期望伤害为 `d·p·[1+c(m−1)]`。若 c 实为所有攻击中的暴击比例，公式就必须重写；不能把变量同名当作假设一致。这里是全期望公式的纸面应用，不是结算实现。

### 2.2 区间、零事件与覆盖率验收

频率学置信区间描述重复抽样程序的覆盖性质。观测到一个区间以后，不把它解释为固定参数随机落入的概率，也不把均值区间当单次攻击或单次延迟的预测区间。二项比例需满足对应试验模型；Wilson 比 Wald 更适合许多小样本/端点场景，但不是“任何输入都精确95%覆盖”的承诺。公式与实现入口见[采样专篇](../随机采样与程序化生成/07-概率分布与采样工程.md)。[NIST 区间说明](https://www.itl.nist.gov/div898/handbook/prc/section2/prc241.htm)

`PAPER_EXPECTED P1`：独立同概率 Bernoulli 试验 n=20、观测 k=0。Wald 代入样本比例会得到 [0,0]，不能据此断言真实 p=0。Wilson 双侧区间用 z=1.96 时化为 `[0, z²/(20+z²)]`，上端约0.161。n=0 时比例与此区间没有定义，应返回无数据；不能用 [0,0] 补齐。上述数字是公式代入，`NOT_RUN`。

若用 R 次相互独立重复试验评估区间覆盖，命中次数 K 自身也随机。设真实覆盖率为 q，则 `K~Binomial(R,q)`，覆盖率估计 K/R 的标准误差为 `√[q(1−q)/R]`。R=100、假设 q=0.95 时约0.0218；因此“100个种子必须落在92%–98%”没有自动获得稳定门禁资格。先规定参数网格、R、误拒率与覆盖检验方法，再保留全部失败。离散模型的真实 q 也可能随参数变化，不能一律代入0.95。[NIST 二项分布](https://www.itl.nist.gov/div898/handbook/eda/section3/eda366i.htm)

按玩家随机分组时，不能把同玩家的每个请求都当独立实验单位。Bootstrap 也必须保留配对、玩家簇或时间相关结构；block bootstrap 需要自己的过程假设，不是任意时间序列的万能修复。稳健估计量（中位数、截尾均值、winsorized 均值）可能改变估计目标，不能换了指标仍宣称在估计同一个总体均值。

A/B 设计应提前写主指标、基线波动、最小有意义效果、显著性/功效、分层方式、随机化单位和停止规则；训练/验证/测试隔离。多个比较应按决策目的选择 FWER 或 FDR 等控制。固定样本检验不可随意“显著就停”；需要序贯方法时，应使用已设计且适配的规则，alpha-spending 只是其中一类。区间跨0表示本次证据不足以支持对应方向差异，不证明两者等效；等效需要预设容许差和相应检验。

## 3. 线性求解：残差为什么不够

### 3.1 先区分问题类型

向量可表示状态，矩阵可表示线性映射；点积不是自动归一化的相似度。特征向量满足 `Av=λv, v≠0`；“主方向”还依赖矩阵结构。判断动态稳定性要区分连续与离散系统，不能仅凭“有特征值”作结论。PCA/SVD 中符号、重根子空间和尺度都会影响比较口径。[NIST DLMF §3.2](https://dlmf.nist.gov/3.2)

| 目标与前提 | 常见选择 | 应报告的限制 |
| --- | --- | --- |
| 方阵、非奇异 Ax=b | 带合适主元策略的 LU；对称正定可用 Cholesky | 非奇异/正定前提、缩放、求解器状态、残差与误差估计 |
| 满列秩最小二乘 | QR 等分解 | 形状、目标范数、数据权重、秩与噪声模型 |
| 秩亏或接近秩亏 | 带秩判断的方法或 SVD | 阈值、选解规则；截断/正则化改变估计问题 |
| 大规模稀疏系统 | 匹配结构的稀疏直接法或迭代法 | CSR/CSC 只是存储方式；填充、预条件、访存、收敛预算另算 |

求解 Ax=b 通常直接调用分解/求解接口，不为拿到 x 先显式形成逆矩阵。逆矩阵若本来就是数学输出，应另行说明；“禁止所有求逆”不是本节合同。正规方程在满列秩、2-范数下有 `κ₂(AᵀA)=κ₂(A)²`，额外放大病态影响；不能仅因为公式短就选它。

### 3.2 可比的误差指标

先对不同物理量明确单位和缩放，再使用一致的向量范数及其诱导矩阵范数。以下示例统一采用无穷范数；A 为非奇异方阵，精确解 x 满足 Ax=b，候选解记为 x̂：

- 残差 `r=b−Ax̂`：单位与 b 相同，回答方程满足得怎样
- 相对残差 `ρ=||r||∞/||b||∞`：仅在 b≠0 时定义
- 范数型后向误差 `η=||r||∞/(||A||∞||x̂||∞+||b||∞)`：以 A、b 同时允许相对扰动为口径，衡量候选解能精确解哪个附近问题
- 相对前向误差 `e=||x̂−x||∞/||x||∞`：仅在 x≠0 且有可信参考解时可直接计算
- 条件数 `κ∞(A)=||A||∞||A⁻¹||∞`：问题对扰动的敏感性；实现可使用条件数估计，不能把估计当精确值

对精确给定 A、b 与精确计算的残差，有 `e≤κ∞(A)ρ`。病态问题允许小残差伴随大解误差；这个上界也不承诺一定达到最坏误差。浮点残差本身还有舍入误差，严格诊断要说明它的计算精度。[NIST DLMF §3.2(iii)](https://dlmf.nist.gov/3.2#iii)

LAPACK 的 `BERR` 使用分量型后向误差，不要把它直接标作上述范数型 η；`FERR` 是前向误差界估计，`RCOND` 是倒条件数估计，且可能针对均衡缩放后的系统。报告必须写它们各自的定义和所对应的系统。[LAPACK 误差说明，1999-10-01](https://www.netlib.org/lapack/lug/node81.html)

分母为0时不得硬除：b=0可改看有定义的 η 和绝对误差；x=0无相对前向误差；η分母为0且一致地算得 r=0时可约定 η=0，同时报告退化输入，不能据此推断解唯一。NaN/Inf 或无法形成有限诊断时返回数值失败。

### 3.3 一个可逐项复核的反例

`PAPER_EXPECTED L1`，所有量无量纲、按精确实数运算：

`A=diag(1,10⁻⁸), x=(1,1), b=(1,10⁻⁸), x̂=(1,0)`

于是 `r=(0,10⁻⁸)`、`ρ=10⁻⁸`、`η=5×10⁻⁹`、`κ∞=10⁸`，但 `e=1`。残差看起来小，第二分量却完全错。再把 A、b 同乘10⁻⁶，绝对残差变为10⁻¹⁴，ρ、η、κ∞和 e 均不变；统一的“残差<10⁻¹⁰即通过”只因缩放就改变判断，不能用作跨问题验收。此处 x̂ 是人为指定的反例，不声称任何库实际返回它；`NOT_RUN`。

“κ·ε大就一定算错”同样过头。它是风险信号；特定右端项仍可能求得准确结果。验收应同时看输入不确定性、缩放/范数、后向误差、参考解或前向误差界、业务允许的输出误差。换双精度能减少舍入，不会恢复输入里已丢失的信息。

## 4. 最小二乘、秩与空诊断

最小二乘求 `min_x ||b−Ax||₂`，通常允许最优残差非零。对无约束实数问题，候选极小点满足 `Aᵀ(b−Ax)=0`；这是驻点关系，不是建议形成正规方程求解。列秩不足时可能有多个最小化解，必须声明最小范数、约束或正则化等选解规则。

`PAPER_EXPECTED L2`：`A=[[1,0],[1,0]], b=(1,3)`。目标是 `(1−x₁)²+(3−x₁)²`；所有 `x=(2,t)` 都最小化，最小2-范数解为 `(2,0)`。残差 `(-1,1)` 非零，平方和为2，而 Aᵀr=0。不能因残差非零判定失败，也不能宣称第二未知量被观测唯一确定；`NOT_RUN`。

NumPy 2.3 的 `lstsq` 返回 x、residuals、rank、s；`residuals` 是平方残差和，并非残差向量。rank<N 或 M≤N 时它为空，**空数组不表示残差为0**。在上面的2×2秩亏案例中，应自己计算 b−Ax 并报告平方和，不能把空摘要默认为成功。文档还规定 `rcond` 用最大奇异值的比例判断秩；默认与机器精度和 max(M,N) 有关，2.0 已改变默认值。[NumPy 2.3 文档](https://numpy.org/doc/2.3/reference/generated/numpy.linalg.lstsq.html)

接口应记录原始/缩放后的 A、b、dtype、M/N、权重、奇异值、rcond、数值秩、求解状态和逆缩放规则。不同单位、噪声量级或阈值下的“数值秩”不同，不等于真实物理自由度突然改变。截断小奇异值可以稳定结果，但引入偏差；阈值应与测量噪声及任务目标一起选择。

PCA 需说明中心化与是否标准化，不能把米与秒的原始方差直接当同尺度重要性。比较重构误差或保留子空间；单个主轴可能翻符号，重特征值下基底也可旋转，逐元素不相等不必然是错误。相机标定、骨骼拟合和轨迹预测还应检查共线/共面、零长度及不可辨识参数。

## 5. 浮点计算：标准格式不等于实现结果

### 5.1 舍入与容差的单位

NIST 对 IEEE 754-2019 的摘要区分 binary32/binary64 等格式；binary64 有53位有效二进制精度。“机器 epsilon”（1到下一个可表示数的间距）和 round-to-nearest 分析中的 unit roundoff 不是同一数，后者为前者的一半。具体库如何处理非有限值、下溢、FMA、扩展精度和编译器重排，需另读实现合同。[DLMF §3.1(i)](https://dlmf.nist.gov/3.1#i)

对有限同单位标量，可以选择显式合同 `|a−b|≤max(atol,rtol·max(|a|,|b|))`；atol 带该量单位，rtol 无量纲。近0时相对阈值不能替代绝对阈值。Python `math.isclose` 使用此口径，NaN不接近任何值，无穷只接近自身；业务 API 可进一步拒绝全部非有限输入。不要假定别的库默认阈值或公式相同。[Python math.isclose](https://docs.python.org/3.14/library/math.html#math.isclose)

一个总体范数可能掩盖小分量的重大相对误差；安全相关的坐标/系数需要分量检查或明确加权尺度。位置、角度、速度和残差不能共享一个没有单位的“1e-6”。

### 5.2 结合律与求和基线

`PAPER_EXPECTED F1`：采用 binary64、每步 round-to-nearest ties-to-even，不重排、不使用更高精度中间结果。令 a=2⁵³、b=1、c=−2⁵³，则 `fl(fl(a+b)+c)=0`，而 `fl(a+fl(b+c))=1`。第一组的 a+b 在两个可表示数正中间舍入到 a；第二组 b+c 可精确表示。因此浮点实现一般不满足结合律。“矩阵结合律误差范围内成立”须改成针对规定输入与归约次序的误差预算，不能把代数恒等式当逐位断言。此为表示推导，`NOT_RUN`。

要比较朴素左折叠、Kahan、pairwise 和高精度参考，先精确定义每个实现。Python 内置 `sum` 从3.12起对浮点采用改进算法，不能在所有 Python 版本里把它当朴素累加；`math.fsum` 通过维护多个部分和提升精度，也有文档所述的中间双舍入限制，不能一律当精确实数真值。[Python sum 版本说明](https://docs.python.org/3.14/library/functions.html#sum)、[fsum 说明](https://docs.python.org/3.14/library/math.html#math.fsum)

固定归约树有助复现，但还需固定输入位模式、dtype、指令/编译策略和库版本；不同线程数或平台末位不同不自动代表算法错误。按绝对值排序可能改变误差与开销，不保证所有带符号、强消去输入都更好。金额/计费采用明确整数最小单位或十进制与舍入规则，排行榜分数则按自身合同选择表示。

### 5.3 稳定表达式与异常出口

平方和优先考虑缩放或 `hypot`；近零的 `exp(x)−1`、`log(1+x)` 可分别使用 `expm1`、`log1p`。它们改善特定运算的精度，不修复错误模型和无效输入。[Python math](https://docs.python.org/3.14/library/math.html)

有限 logits 的 softmax 常先减最大值，使最大指数为1。全为−Inf、含NaN、正Inf或空输入须另定策略；减最大值不能解决所有非有限情况。极小概率可在 log-domain 表达，但仍要定义零概率、归一化和下溢影响。诊断计数应针对业务后果；下溢不必无条件触发告警，关键是有意允许、统计损失或拒绝输入，不能默默伪装成有效结果。

## 6. 求根、优化与有限停止

### 6.1 Newton：从切线得到更新，再检查是否还能继续

在 xₙ 处用切线近似 `f(xₙ+Δx)≈f(xₙ)+f′(xₙ)Δx`。令切线值为0，且 f′(xₙ)≠0，得到 `Δx=−f(xₙ)/f′(xₙ)`，因此：

`xₙ₊₁=xₙ−f(xₙ)/f′(xₙ)`

每一步先在定义域内求 f(xₙ)，按预先声明的标准检查是否已满足目标；未满足才求导数、计算更新、检查新点并推进。不能先除以导数再检查它是否为0。局部快速收敛依赖光滑性、合适初值及简单根等条件；公式存在不保证任意初值收敛。[NIST DLMF §3.8(ii)，式3.8.4](https://dlmf.nist.gov/3.8#ii)

`PAPER_EXPECTED R1`：f(x)=x³−2x+2，故 `f′(x)=3x²−2`，从 x₀=0 按精确实数运算，最多更新两次：

| 更新 | 当前点与函数/导数 | 真实代入 | 下一点 |
| --- | --- | --- | --- |
| 0→1 | x₀=0；f(0)=2；f′(0)=−2 | x₁=0−2/(−2) | 1 |
| 1→2 | x₁=1；f(1)=1；f′(1)=1 | x₂=1−1/1 | 0 |

x₂再次等于x₀，且 f(x₂)=2，不是根。若实现记录到此循环，返回 `CYCLE`；否则达到两次更新上限返回 `MAX_ITERATIONS`，同时带上末点、残差与实际更新数。不能继续无限重试，也不能把“重复同一个点”当收敛。本表是`PAPER_EXPECTED`人工代入；同输入的程序运行终态另见§6.4。

实现须在更新前后处理以下分支：

- 输入、函数值、导数、步长或新点非有限时返回数值失败；新点越出函数定义域时拒绝该步
- 导数为0或在声明单位/尺度下过小时，停止并报告导数问题；不能随意加一个epsilon继续除。若已经维护合法括区间，可以按预先约定改走二分保护步，否则没有自动安全回退
- xₙ₊₁与xₙ在浮点表示中相同，但目标残差仍不合格时返回停滞；重复点可用于有限历史的循环诊断，近似循环判断须另有容差
- 明确最大更新次数、函数/导数求值预算和时间预算；预算耗尽保留有效末点但不标成功。调用次数上限不保证单次函数求值本身能在硬期限内返回

### 6.2 二分法：维持“连续且端点异号”的括区间

给定有限 a<b，要求实函数在整个[a,b]连续并有定义，端点函数值可正确判断符号。端点或中点计算值为NaN/Inf时先返回数值失败。先处理端点已是根的情形；否则要求 f(a)、f(b)严格异号。连续性与介值定理保证区间内至少有一个根，不保证唯一。仅有异号而区间存在极点时不能使用这项保证。

一次更新的数学步骤是：

1. 取中点 `m=(a+b)/2`，求 f(m)。在精确模型中，f(m)=0则找到根
2. 若 f(a)与f(m)异号，保留左半区：`b←m, f(b)←f(m)`
3. 否则，因 f(m)非零且原端点异号，f(m)与f(b)异号，保留右半区：`a←m, f(a)←f(m)`

每次保留的半区仍连续、端点异号，所以至少一个根仍在其中；其宽度变为原来一半。实现应直接比较符号，避免用f(a)·f(b)或f(a)·f(m)的乘积造成溢出/下溢。浮点中点应采用目标库保证安全的midpoint或在受限输入域证明安全的表达式；直接(a+b)/2可能溢出，a+(b−a)/2也不对所有有限异号端点安全。若不能形成有限且严格位于端点之间的中点，而宽度目标仍未满足，应返回停滞/表示限制，不能把端点重复当进展。函数求值若下溢成0或符号不可信，也不能直接继承精确介值保证，应按求值精度合同处理。

`PAPER_EXPECTED R2`：f(x)=x²−2，在[1,2]连续，f(1)=−1、f(2)=2。示例要求区间宽度≤0.01，最多两次中点更新；所有变量无量纲，采用精确分数：

| 更新前区间 | 中点及函数值 | 保留理由 | 更新后区间与宽度 |
| --- | --- | --- | --- |
| [1,2] | m=3/2；f(m)=9/4−2=1/4 | f(1)<0、f(m)>0，保留左半区 | [1,3/2]；宽1/2 |
| [1,3/2] | m=5/4；f(m)=25/16−2=−7/16 | f(m)<0、f(3/2)>0，保留右半区 | [5/4,3/2]；宽1/4 |

两次更新后宽1/4仍大于0.01，返回 `MAX_ITERATIONS` 和当前有效括区间，不宣称达到精度目标。本表是`PAPER_EXPECTED`有限手工追踪；同输入的程序观测另见§6.4。反例f(x)=1/x在[−1,1]端点异号，却在0无定义且无零点；应拒绝该括区间，不把二分遇到的极点当根。[NIST DLMF §3.8(iii)，Bisection Method](https://dlmf.nist.gov/3.8#iii)

### 6.3 停止信号分别证明什么

- **函数残差** `|f(x)|≤τ_f`：τ_f与f同单位，表示方程满足程度。小残差不直接保证x接近根，平坦函数或缩放都可能使残差小；需要导数/条件信息或有效括区间支持位置误差
- **区间宽度** `b−a≤τ_x`：τ_x与x同单位。在有效括区间的精确模型中，返回当前区间中点与其中至少一个根的距离不超过宽度一半；若返回某个端点，不能沿用这一半宽界。浮点严格界还需计入中点和端点计算误差
- **预算**：只证明已停止工作，不证明根已找到或容差已满足。先声明使用哪个成功标准、是否组合条件及判断优先级，达到次数/时间上限时返回独立的未收敛状态

梯度下降还需声明目标、约束、步长/线搜索、梯度来源与终止标准。小步长可能只是停滞，小残差不必代表变量误差小。残差或目标不保证每步单调下降；是否回退应由算法合同决定，不能一上升就机械判错。返回至少区分收敛、预算耗尽、无效输入、非有限计算、不可行和停滞，保留当前最佳有效值是否可用的标志。

梯形、辛普森等求积与 ODE 时间积分是不同问题；前者依赖被积函数光滑性/区间划分，后者还要处理状态与稳定性。旋转归一化或重正交化只适用于明确的旋转约束，不能替代积分误差分析，更不能无条件作用于含缩放/剪切矩阵。实现细节回到相应[积分](05-数值积分与运动学模拟.md)与[旋转](02-四元数与旋转.md)专篇。

### 6.4 完整可运行小程序：先复现终态，再考虑进阶

把下面**整个代码块**保存为 `roots_demo.py`，用现有 Python 3.12 解释器执行 `python3 -I roots_demo.py`。只使用标准库，不需要安装依赖。两个函数直接实现前述更新；main给完整输入和预期输出，并对结果逐项断言。

这个教学版有意收窄接口：状态与容差必须是有限的内置float，容差非负，更新上限是0到64的内置int（不接受bool）。f/df应是同步、能结束、返回float的函数；本次只运行main里的小多项式及返回Inf的故障输入，没有运行任意外部回调。64是示例保护上限，不是收敛保证。

Newton输出依次为 `(status, x, f(x), updates)`；updates只计新点与函数值均有限的已完成更新，初始检查不计入。残差验收优先于停滞/循环，零预算仍允许检查初始点是否已经满足目标；未满足就返回 `MAX_ITERATIONS`。

二分输出为 `(status, a, b, point, f(point)或None, updates)`。调用者仍须保证整个区间连续，端点判号不能证明它；这里只对选定多项式使用该保证。端点零值优先，其次每步按宽度、预算、内部中点、求值与保半区推进。若因宽度或预算返回尚未求值的中点，残差字段必须是None。计算宽度溢出时明确失败，未声称覆盖所有有限float端点；浮点函数值为0也只表示本次计算值为0，不证明任意真实函数具有精确根。

`CONVERGED_WIDTH`表示**计算出的**括区间宽度满足容差；返回的是舍入后的中点，不是严格区间算术。精确半宽数学界与浮点舍入界仍按§6.3区分。`STAGNATION`、`CYCLE`、`DERIVATIVE_TOO_SMALL`、`INVALID_INPUT`、`INVALID_BRACKET`、`NUMERIC_FAILURE`和预算耗尽都不是成功。

```python
import json
import math
import sys


def newton(f, df, x0, *, f_tol, max_updates, df_tol=0.0):
    # Result: (status, last finite x, f(x), completed finite updates).
    valid = (
        callable(f) and callable(df)
        and type(x0) is float and math.isfinite(x0)
        and type(f_tol) is float and math.isfinite(f_tol) and f_tol >= 0.0
        and type(df_tol) is float and math.isfinite(df_tol) and df_tol >= 0.0
        and type(max_updates) is int and 0 <= max_updates <= 64
    )
    if not valid:
        return ("INVALID_INPUT", None, None, 0)
    x = x0
    try:
        fx = f(x)
    except (ArithmeticError, ValueError):
        return ("NUMERIC_FAILURE", x, None, 0)
    if type(fx) is not float or not math.isfinite(fx):
        return ("NUMERIC_FAILURE", x, None, 0)
    if abs(fx) <= f_tol:
        return ("CONVERGED_RESIDUAL", x, fx, 0)
    seen = {x}
    for used in range(1, max_updates + 1):
        try:
            slope = df(x)
            if type(slope) is not float or not math.isfinite(slope):
                return ("NUMERIC_FAILURE", x, fx, used - 1)
            if abs(slope) <= df_tol:
                return ("DERIVATIVE_TOO_SMALL", x, fx, used - 1)
            step = fx / slope
            next_x = x - step
            if not math.isfinite(step) or not math.isfinite(next_x):
                return ("NUMERIC_FAILURE", x, fx, used - 1)
            next_fx = f(next_x)
        except (ArithmeticError, ValueError):
            return ("NUMERIC_FAILURE", x, fx, used - 1)
        if type(next_fx) is not float or not math.isfinite(next_fx):
            return ("NUMERIC_FAILURE", x, fx, used - 1)
        if abs(next_fx) <= f_tol:
            return ("CONVERGED_RESIDUAL", next_x, next_fx, used)
        if next_x == x:
            return ("STAGNATION", next_x, next_fx, used)
        if next_x in seen:
            return ("CYCLE", next_x, next_fx, used)
        seen.add(next_x)
        x, fx = next_x, next_fx
    return ("MAX_ITERATIONS", x, fx, max_updates)


def bisect(f, a, b, *, x_tol, max_updates):
    # Caller promises continuity on [a,b]; sign checks cannot prove it.
    # Result: (status, a, b, point, f(point) or None, completed updates).
    valid = (
        callable(f)
        and type(a) is float and math.isfinite(a)
        and type(b) is float and math.isfinite(b) and a < b
        and type(x_tol) is float and math.isfinite(x_tol) and x_tol >= 0.0
        and type(max_updates) is int and 0 <= max_updates <= 64
    )
    if not valid:
        return ("INVALID_INPUT", None, None, None, None, 0)
    try:
        fa, fb = f(a), f(b)
    except (ArithmeticError, ValueError):
        return ("NUMERIC_FAILURE", a, b, None, None, 0)
    if (type(fa) is not float or type(fb) is not float
            or not math.isfinite(fa) or not math.isfinite(fb)):
        return ("NUMERIC_FAILURE", a, b, None, None, 0)
    if fa == 0.0:
        return ("CONVERGED_ENDPOINT", a, b, a, fa, 0)
    if fb == 0.0:
        return ("CONVERGED_ENDPOINT", a, b, b, fb, 0)
    if (fa > 0.0) == (fb > 0.0):
        return ("INVALID_BRACKET", a, b, None, None, 0)
    for used in range(max_updates + 1):
        width = b - a
        if not math.isfinite(width):
            return ("NUMERIC_FAILURE", a, b, None, None, used)
        mid = a + width / 2.0
        if not math.isfinite(mid):
            return ("NUMERIC_FAILURE", a, b, None, None, used)
        if width <= x_tol:
            return ("CONVERGED_WIDTH", a, b, mid, None, used)
        if used == max_updates:
            return ("MAX_ITERATIONS", a, b, mid, None, used)
        if not a < mid < b:
            return ("STAGNATION", a, b, mid, None, used)
        try:
            fm = f(mid)
        except (ArithmeticError, ValueError):
            return ("NUMERIC_FAILURE", a, b, mid, None, used)
        if type(fm) is not float or not math.isfinite(fm):
            return ("NUMERIC_FAILURE", a, b, mid, None, used)
        if fm == 0.0:
            return ("CONVERGED_VALUE", a, b, mid, fm, used + 1)
        if (fa > 0.0) != (fm > 0.0):
            b, fb = mid, fm
        else:
            a, fa = mid, fm
    raise AssertionError("unreachable")


if __name__ == "__main__":
    print(json.dumps({
        "python": sys.version,
        "platform": sys.platform,
        "float_mant_dig": sys.float_info.mant_dig,
        "float_rounds": sys.float_info.rounds,
        "max_allowed_updates": 64,
    }, ensure_ascii=False))
    f = lambda x: x*x*x - 2.0*x + 2.0
    df = lambda x: 3.0*x*x - 2.0
    square_minus_two = lambda x: x*x - 2.0
    linear = lambda x: x - 2.0
    one = lambda x: 1.0
    # Non-finite callback is a deliberate input fault, not a polynomial model.
    bad_value = lambda x: math.inf
    adjacent = math.nextafter(1.0, 2.0)
    cases = [
        ("R1", newton(f, df, 0.0, f_tol=0.0, max_updates=2),
         ("CYCLE", 0.0, 2.0, 2)),
        ("N_normal", newton(linear, one, 0.0, f_tol=0.0, max_updates=2),
         ("CONVERGED_RESIDUAL", 2.0, 0.0, 1)),
        ("N_budget", newton(f, df, 0.0, f_tol=0.0, max_updates=1),
         ("MAX_ITERATIONS", 1.0, 1.0, 1)),
        ("N_empty", newton(f, df, 0.0, f_tol=0.0, max_updates=0),
         ("MAX_ITERATIONS", 0.0, 2.0, 0)),
        ("N_zero_derivative",
         newton(lambda x: x*x + 1.0, lambda x: 2.0*x, 0.0,
                f_tol=0.0, max_updates=2),
         ("DERIVATIVE_TOO_SMALL", 0.0, 1.0, 0)),
        ("N_nonfinite", newton(bad_value, one, 0.0,
                               f_tol=0.0, max_updates=2),
         ("NUMERIC_FAILURE", 0.0, None, 0)),
        ("N_invalid", newton(f, df, math.nan, f_tol=0.0, max_updates=2),
         ("INVALID_INPUT", None, None, 0)),
        ("N_limit", newton(f, df, 0.0, f_tol=0.0, max_updates=65),
         ("INVALID_INPUT", None, None, 0)),
        ("N_stagnation",
         newton(lambda x: (x - 1.0) + 2.0**-54, one, 1.0,
                f_tol=0.0, max_updates=2),
         ("STAGNATION", 1.0, 2.0**-54, 1)),
        ("R2", bisect(square_minus_two, 1.0, 2.0,
                      x_tol=0.01, max_updates=2),
         ("MAX_ITERATIONS", 1.25, 1.5, 1.375, None, 2)),
        ("B_width", bisect(square_minus_two, 1.0, 2.0,
                           x_tol=0.25, max_updates=2),
         ("CONVERGED_WIDTH", 1.25, 1.5, 1.375, None, 2)),
        ("B_root", bisect(linear, 1.0, 3.0, x_tol=0.0, max_updates=2),
         ("CONVERGED_VALUE", 1.0, 3.0, 2.0, 0.0, 1)),
        ("B_endpoint", bisect(linear, 2.0, 3.0,
                              x_tol=0.0, max_updates=2),
         ("CONVERGED_ENDPOINT", 2.0, 3.0, 2.0, 0.0, 0)),
        ("B_invalid_bracket",
         bisect(lambda x: x*x + 1.0, -1.0, 1.0,
                x_tol=0.0, max_updates=2),
         ("INVALID_BRACKET", -1.0, 1.0, None, None, 0)),
        ("B_invalid", bisect(linear, 3.0, 1.0,
                             x_tol=0.0, max_updates=2),
         ("INVALID_INPUT", None, None, None, None, 0)),
        ("B_nonfinite", bisect(bad_value, 0.0, 1.0,
                               x_tol=0.0, max_updates=2),
         ("NUMERIC_FAILURE", 0.0, 1.0, None, None, 0)),
        ("B_empty", bisect(square_minus_two, 1.0, 2.0,
                           x_tol=0.0, max_updates=0),
         ("MAX_ITERATIONS", 1.0, 2.0, 1.5, None, 0)),
        ("B_stagnation",
         bisect(lambda x: 2.0*(x - 1.0) - 2.0**-52, 1.0, adjacent,
                x_tol=0.0, max_updates=2),
         ("STAGNATION", 1.0, adjacent, 1.0, None, 0)),
    ]
    for name, actual, expected in cases:
        print(json.dumps({"case": name, "result": actual,
                          "expected": expected, "pass": actual == expected},
                         ensure_ascii=False, allow_nan=False))
        assert actual == expected, (name, actual, expected)
    print("PASS: 18 finite cases")
```

## 7. 误差预算必须能传播到输出

把测量噪声、模型偏差、抽样不确定性、离散化、舍入、实现缺陷分开记录。系统性偏差不会因为样本增多自动变成零；确定性最坏界也不是标准差，不能把它们混在一个“方差和”里。

对于明确随机输入 X 及小扰动，可用一阶线性化 `Σ_y≈JΣ_xJᵀ`，J为输出对输入的雅可比；线性变换时该协方差关系精确，非线性时是局部近似。协方差项不能在没有依据时删去；独立足以推出零协方差，但零协方差不足以证明独立。非线性强、尾部重或不确定性大时，应检查线性化适用性。[NIST 误差传播](https://www.itl.nist.gov/div898/handbook/mpc/section5/mpc55.htm)

`PAPER_EXPECTED E1`：同一测量误差 Z 被两个通道重复使用，Var(Z)=σ²。输出 Y=Z−Z 恒为0；保留协方差得 `Var(Y)=σ²+σ²−2σ²=0`。误当独立会得到2σ²。反之 Y=Z+Z 的方差为4σ²，独立假设会低估为2σ²；`NOT_RUN`。

| 来源 | 应填写的量及单位 | 传播口径与观测 |
| --- | --- | --- |
| 测量 | 各坐标的偏差、标准差、协方差；如m、rad | 校准与配对观测，记录输出敏感度 |
| 网络时间戳 | 时间误差 δt，单位s | 在局部匀速假设下 δx≈v·δt；v单位m/s，结果m |
| 离散化 | 步长/网格与局部、全局误差 | 收敛阶与稳定域前提；不能只重复累加同一常量 |
| 舍入 | dtype、运算次数、尺度与消去 | 最坏界/经验分布分别声明；不是默认每步独立随机游走 |
| 模型简化 | 参考模型与现实差异，输出单位 | 离线参考、保留数据和线上信号；不可伪装成数值残差 |
| 实现缺陷 | 形状错、错误广播、错单位、状态泄漏 | 边界与失败用例；应修正，不分配“可接受bug预算” |

“速度误差积分到位置”与“位置初始误差随系统动力学传播”要按状态方程区分。不能笼统说位置误差经过速度积分；也不能把网络重传时延直接加成位置误差而不引入运动模型。
