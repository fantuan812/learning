# 网络分层、协议与工程实践

> 知识成熟度：L2（协议原理与 RFC 核对；端到端指标需目标网络复测）。

> 知识基线：TCP/IP、UDP、TLS 1.3 与 RFC 9293；实现行为以目标 OS 和库版本为准。
> 最后更新：2026-08-20。
> 官方参考：[RFC 9293 TCP](https://www.rfc-editor.org/rfc/rfc9293)、[RFC 9000 QUIC](https://www.rfc-editor.org/rfc/rfc9000)。
> 验证入口：使用 tcpdump/Wireshark、netem 与端到端压测复现文中结论。
> 验证与基准：记录握手时延、吞吐、丢包与重传的 P50/P95/P99。

## 学习路线
1. 先理解分层和封装。
2. 再掌握寻址、路由与可靠传输。
3. 最后进行性能、安全和故障排查。

## 1. 分层模型
4. 物理层传输比特。
5. 数据链路层传输帧。
6. 网络层传输分组。
7. 传输层提供端到端语义。
8. 会话和表示层常由应用实现。
9. 应用层定义业务协议。
10. 封装会增加头部开销。
11. 解封装按相反顺序进行。
12. MTU 限制单帧有效载荷。
13. MSS 通常小于路径 MTU。
14. 分层便于替换实现。
15. 跨层优化需谨慎验证。

## 2. 以太网与链路
16. MAC 地址标识链路接口。
17. 交换机依据 MAC 表转发。
18. ARP 将 IPv4 映射为 MAC。
19. 邻居缓存减少重复解析。
20. VLAN 划分广播域。
21. Trunk 携带多个 VLAN。
22. STP 防止二层环路。
23. LACP 聚合多条物理链路。
24. 全双工避免碰撞检测。
25. CRC 检测帧传输错误。
26. 广播过多会消耗交换资源。
27. Jumbo frame 需端到端一致。
28. 网卡卸载可降低 CPU 负载。
29. TSO/GSO 合并大段发送。
30. GRO/LRO 合并接收报文。

## 3. IP 寻址
31. IPv4 地址由网络和主机部分组成。
32. CIDR 用前缀长度表示子网。
33. 子网划分控制地址范围。
34. 私有地址不可在公网直接路由。
35. NAT 修改地址或端口。
36. IPv6 地址空间更大。
37. IPv6 使用邻居发现协议。
38. 双栈同时运行两种协议。
39. 默认路由匹配所有未知目的地。
40. 最长前缀匹配优先。
41. 环回地址用于本机测试。
42. 链路本地地址只在本链路有效。
43. DHCP 动态分配 IPv4 配置。
44. SLAAC 可自动生成 IPv6 地址。
45. 地址冲突会导致间歇性故障。

## 4. 路由
46. 路由表决定下一跳。
47. 静态路由适合简单拓扑。
48. 动态路由协议交换可达性。
49. OSPF 基于链路状态。
50. BGP 基于路径向量。
51. 度量决定优选路径。
52. ECMP 可利用等价路径。
53. 路由收敛存在时间窗口。
54. 路由环路会产生 TTL 消耗。
55. TTL 防止分组无限循环。
56. ICMP 报告网络层错误。
57. traceroute 利用 TTL 递增。
58. 黑洞路由丢弃特定前缀。
59. ACL 可过滤来源和目的地。
60. 路由策略影响出口选择。

## 5. TCP
61. TCP 提供可靠字节流。
62. 三次握手建立连接。
63. 序列号标识字节位置。
64. ACK 确认已接收数据。
65. 滑动窗口控制未确认数据。
66. 接收窗口实现流量控制。
67. 拥塞窗口实现拥塞控制。
68. 慢启动逐步增加发送速率。
69. 拥塞避免降低增长斜率。
70. 快速重传依赖重复 ACK。
71. RTO 估计超时重传。
72. TIME_WAIT 防止旧报文干扰。
73. Keepalive 检测空闲对端。
74. Nagle 合并小报文。
75. 延迟 ACK 影响交互延迟。
76. TCP_NODELAY 关闭 Nagle。
77. 半关闭允许单向结束。
78. 连接池减少握手成本。
79. 端口四元组唯一标识连接。
80. SYN flood 消耗半连接队列。

## 6. UDP 与实时传输
81. UDP 无连接且开销较低。
82. UDP 不保证顺序和可靠性。
83. 应用可自行实现重传。
84. DNS 常使用 UDP。
85. QUIC 在 UDP 上实现可靠流。
86. RTP 携带实时音视频序号。
87. 抖动缓冲平滑到达时间。
88. 丢包隐藏降低感知影响。
89. FEC 用冗余恢复部分丢包。
90. 实时系统更重视延迟上界。

## 7. TLS 与安全
91. TLS 提供机密性、完整性和认证。
92. 握手协商版本与密码套件。
93. 证书链验证服务器身份。
94. SNI 指示目标虚拟主机。
95. ALPN 协商 HTTP/2 或 HTTP/3。
96. 会话恢复减少握手往返。
97. 前向保密依赖临时密钥。
98. 禁用过时协议和弱密码。
99. HSTS 强制使用 HTTPS。
100. 证书过期会导致大面积失败。
101. 密钥轮换降低泄露影响。
102. mTLS 同时认证客户端和服务端。
103. 加密不能替代授权。
104. 最小权限限制横向移动。
105. 网络分段缩小攻击面。

## 8. DNS
106. 递归解析器代表客户端查询。
107. 权威服务器维护真实记录。
108. 根、顶级域和权威构成层次。
109. TTL 控制缓存时间。
110. A 记录映射 IPv4。
111. AAAA 记录映射 IPv6。
112. CNAME 提供别名。
113. MX 指定邮件服务器。
114. TXT 可承载验证信息。
115. NXDOMAIN 表示名称不存在。
116. DNSSEC 为记录提供签名验证。
117. 分流 DNS 按来源返回不同地址。
118. 缓存污染会导致错误解析。
119. 域名切换应降低 TTL 后再操作。
120. 监控解析成功率和延迟。

## 9. HTTP
121. HTTP 请求包含方法、路径和头部。
122. GET 应保持幂等。
123. POST 通常创建或触发动作。
124. PUT 用于完整替换资源。
125. PATCH 用于部分更新。
126. 状态码分为五类。
127. 2xx 表示成功。
128. 3xx 表示重定向。
129. 4xx 表示客户端错误。
130. 5xx 表示服务端错误。
131. Cache-Control 控制缓存策略。
132. ETag 支持条件请求。
133. Cookie 保存会话状态。
134. SameSite 降低跨站请求风险。
135. CORS 控制跨源访问。
136. HTTP/2 使用多路复用。
137. HTTP/3 基于 QUIC。
138. 头部压缩减少重复字段。
139. 流式响应降低首字节等待。
140. 连接复用减少握手开销。

## 10. 性能
141. RTT 决定交互最低往返时间。
142. 带宽决定大流量上限。
143. BDP 等于带宽乘 RTT。
144. 窗口应覆盖链路 BDP。
145. 丢包会触发重传和降速。
146. 队头阻塞影响串行队列。
147. 缓冲膨胀导致高延迟。
148. ECN 可提前标记拥塞。
149. DSCP 标记服务质量类别。
150. 限速器应平滑突发流量。
151. 连接预热改善首包延迟。
152. CDN 将内容靠近用户。
153. 边缘缓存减少源站负载。
154. 压缩需权衡 CPU 和带宽。
155. 批量请求减少协议开销。

159. tcpdump 捕获原始报文。

161. ip route 查看路由表。

163. dig 检查 DNS 记录。
164. curl 验证 HTTP 行为。

166. netstat 适合旧系统。
167. ethtool 查看网卡计数器。
168. conntrack 观察 NAT 状态。
169. 防火墙日志记录丢弃原因。
170. 指标区分客户端和服务端错误。
171. 日志应包含连接和请求标识。
172. 分布式追踪展示跨服务耗时。
173. 采样率需控制存储成本。
174. 抓包注意隐私与密钥保护。
175. 先确认范围再缩小故障域。

## 12. 故障排查流程
176. 复现问题并记录时间窗口。
177. 检查 DNS 是否解析正确。
178. 检查本机路由和默认网关。
179. 检查 ARP 或邻居状态。
180. 检查防火墙和安全组。
181. 检查 TCP 握手是否完成。
182. 检查 TLS 证书和时间。
183. 检查 HTTP 状态码和响应头。
184. 比较不同地域和网络运营商。
185. 区分单连接与全局容量问题。
186. 观察重传、拥塞和窗口。
187. 检查服务端监听地址。
188. 检查端口耗尽和文件描述符。
189. 检查连接池和线程池上限。
190. 对照变更记录回滚验证。

## 13. 可靠性设计
191. 设置合理连接和读写超时。
192. 重试只用于可重试错误。
193. 重试必须有上限和退避。
194. 幂等键防止重复写入。
195. 熔断隔离异常依赖。
196. 舱壁限制并发资源。
197. 限流保护核心服务。
198. 降级返回可接受的旧数据。
199. 多区域部署降低单点风险。
200. 健康检查区分存活和就绪。
201. 滚动发布控制变更半径。
202. DNS 故障转移需要验证 TTL。
