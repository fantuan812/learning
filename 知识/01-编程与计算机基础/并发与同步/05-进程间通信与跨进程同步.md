# 05-进程间通信与跨进程同步

> 知识成熟度：L2。主要承诺是解释通道选择、共享对象生存期、所有者死亡、SPSC 顺序、FD 引用交付和状态通知的合同；局部 Linux 练习不构成可移植无锁 IPC、任意崩溃恢复或生产热迁移证明。`verified: []` 不因程序运行而自动生成验证事件。
> 本次修订：2026-10-06。API 资料主要为 Linux man-pages 6.19；本次 `_exit(2)` 页面为 6.18。C++ 使用 N4861 工作草案，Windows 只作官方文档对照。详细定位及未覆盖项见第 6 节。

读者面对的实际问题是：守护进程与游戏服务如何交换控制消息或快照；谁能写共享状态；对方在中途退出后，自己是否已经拿到锁、数据或资源引用；最后谁负责收尾。选择机制之前先确定这四种所有权。前置知识是进程的独立虚拟地址空间、文件描述符与线程互斥。

## 1. 按消息、共享状态和通知选择通道

| 机制 | 提供的东西 | 需要自行规定的合同 | 常见用途与代价 |
| --- | --- | --- | --- |
| pipe / FIFO | 有容量限制的字节流；没有应用消息边界 | 分帧、背压、端点关闭、EOF；没有读端时的 SIGPIPE/EPIPE | 子进程输入输出、构建工具；复制的写端未关可能延迟 EOF |
| AF_UNIX SOCK_STREAM | 双向字节流及辅助数据 | 分帧、部分传输、鉴权与关闭责任 | 本机控制通道；不能把一次 send 当一条完整接收消息 |
| AF_UNIX SOCK_SEQPACKET | 有序、有记录边界的连接通道 | 最大记录、截断拒收、背压、FD 清理 | 本文 FD 小协议；不是所有系统都支持相同扩展 |
| MAP_SHARED 共享映射 | 多个地址空间引用同一后备存储 | 唯一初始化、格式、同步、恢复、发布与退役 | 大快照或批量数据；减少通道搬运，但增加共享状态责任 |
| eventfd | Linux 计数通知、可等待的 fd | 数据谓词、合并语义、丢通知窗口、最后引用关闭 | 提醒消费者重新检查共享状态；不是消息内容或剩余任务数 |
| signalfd | Linux signal 信息记录 | signal mask、线程间信号递送与处理责任 | 将选定信号纳入事件循环；不是 eventfd 式整数计数器 |

没有通用的“固定两次复制”“运行期零陷入”或吞吐排名。共享内存仍有业务复制、缺页、缓存一致性、竞争与通知成本；无竞争的 pthread mutex 路径也不必每次都进入内核。需要少量控制信息时，消息通道通常更容易定义失败边界。参见 [pipe(7)](https://man7.org/linux/man-pages/man7/pipe.7.html)、[unix(7)](https://man7.org/linux/man-pages/man7/unix.7.html)、[signalfd(2)](https://man7.org/linux/man-pages/man2/signalfd.2.html)。

## 2. 共享对象：从唯一初始化到安全退役

### 2.1 name、fd 和 mapping 是三种不同的引用

```text
name ──shm_open──> fd ──mmap(MAP_SHARED)──> 进程 A 的映射
本例：A 已有的映射 ──fork 继承──> B 的映射（原 SHM fd 在 fork 前已关闭）
独立 FD 交付：发送者持有的 fd ──SCM_RIGHTS──> B 的 fd ──验证后 mmap──> B 的映射
A 的映射与 B 的映射 ────────────────────> 同一个共享后备存储
name / fd / mapping 是三类引用；各进程的虚拟地址可以不同
shm_unlink 删除名字；close 释放本地 fd；munmap 解除本进程映射
映射存在不代表业务已同步或持久化；独立加入的发布协议不在本例内
```

`shm_open(O_CREAT|O_EXCL)` 原子检查并创建新对象，初始大小为零；唯一创建者先定大小再映射，使用期间不再截断。新对象的零填充存储不等于 mutex 已初始化，必须实际调用并检查 pthread 初始化。`close(fd)` 不撤销现有映射；`shm_unlink` 使后来不能再用该名字打开这一代对象，旧引用仍可存续。Linux 常由 tmpfs 支持它，不等于所有页永驻物理内存。见 [shm_open(3)](https://man7.org/linux/man-pages/man3/shm_open.3.html)、[mmap(2)](https://man7.org/linux/man-pages/man2/mmap.2.html) 和 [shm_overview(7)](https://man7.org/linux/man-pages/man7/shm_overview.7.html)。

独立启动的加入者不能看到普通 `READY` 布尔值就碰 mutex。可行设计是可信创建者完成大小、格式与 mutex 初始化后，经受控通道分发对象 FD 和加入许可；接收者检查格式、代次、大小与 ABI，才开始使用。这还需要独立的发布、身份和退役协议。本例直接在初始化完成后 fork，只覆盖继承已初始化映射，不实现上述加入服务。

独立进程共享的格式不能依赖本地裸地址、虚表、分配器或进程内句柄。固定字节格式或 offset+length 也必须验证：先 `offset <= total`，再 `length <= total - offset`，并约定版本、字节序与布局。`pthread_mutex_t` 本身是实现 ABI 对象，不能拿其字节作跨版本持久化格式。

### 2.2 robust 报告死亡，应用决定数据能否修复

先取得共享存储，在独立 attr 对象上分别设置 `PTHREAD_PROCESS_SHARED` 和 `PTHREAD_MUTEX_ROBUST`，所有 setter 成功后直接在共享位置调用 `pthread_mutex_init`；不复制已经初始化的 mutex。默认 private mutex 或标准 `std::mutex` 不能凭“放进 mmap”获得本文的跨进程承诺；这也不表示所有 IPC 都必须用 pthread。属性不支持、初始化失败均应停止，pthread API 返回错误号，不能用 `errno` 替代。[属性合同](https://man7.org/linux/man-pages/man3/pthread_mutexattr_setpshared.3.html)和 [robust 状态转换](https://man7.org/linux/man-pages/man3/pthread_mutexattr_setrobust.3.html)决定下面的所有权：

| lock 返回 | 当前是否持锁 | 本文的处置 |
| --- | --- | --- |
| 0 | 是 | 验证并使用数据，检查 unlock 结果 |
| EOWNERDEAD | 是 | 数据视为不一致；修复业务不变量后 consistent，或明确拒修后 unlock |
| ENOTRECOVERABLE | 否 | 停用并退役这一代；不能再 unlock 或原地重新初始化给旧参与者用 |
| 其他非零值 | 不当作成功 | 停止业务并记录；不能统一跳到 destroy/munmap |

`pthread_mutex_consistent` 只声明应用已修好数据，不替应用修数据。若持有 EOWNERDEAD 锁却不 consistent 就解锁，后续获取会得到 ENOTRECOVERABLE。恢复者再次持锁死亡仍可能再次触发 EOWNERDEAD；“健壮”不等于余额、订单或事务自动恢复。[consistent(3)](https://man7.org/linux/man-pages/man3/pthread_mutex_consistent.3.html)明确把数据恢复责任留给应用。

### 2.3 完整有限练习：可丢弃 mailbox

下面 `robust_mailbox.c` 是完整 C11 程序。限定 Linux、支持这两种 pthread 属性的 libc、同一个二进制、启动以来单线程的父进程、一名 child、无外部参与者、fork 时 mutex 未持有。代码不创建线程，并在入口及 fork 前读取自己的 `/proc/self/task` 验证当前只有一个线程；这两个快照不能代替“宿主不得曾经启动后台线程”的使用前提，所以不要把它嵌进多线程服务器。若检测不满足，练习失败而非改跑模拟器。

业务合同先于修复代码：mailbox 是允许整条丢弃的临时消息；空态为 length=0、payload 全零。normal 消费也可清空，repair 可直接重建整个 mailbox 子对象；绝不清零 mutex。损坏长度只写入可表示的 capacity+1，不按它索引数组。每个进程调用一次 `normal`、`repair` 或 `poison`，每次 fresh 创建。

```c
/* robust_mailbox.c: Linux-only, standalone, one parent and one child. */
#define _GNU_SOURCE
#include <dirent.h>
#include <errno.h>
#include <fcntl.h>
#include <inttypes.h>
#include <pthread.h>
#include <signal.h>
#include <stdint.h>
#include <stdio.h>
#include <stdlib.h>
#include <string.h>
#include <sys/mman.h>
#include <sys/stat.h>
#include <sys/types.h>
#include <sys/wait.h>
#include <unistd.h>

enum { CAP = 16, CHILD_OK = 20, CHILD_INJECTED = 21, CHILD_FAILED = 90 };
typedef struct { uint32_t length; unsigned char bytes[CAP]; } Mailbox;
typedef struct { pthread_mutex_t mutex; Mailbox box; } Shared;

static int perr(const char *what, int e) {
    fprintf(stderr, "%s: %s (%d)\n", what, strerror(e), e);
    return -1;
}
static int close_once(int *fd) {
    if (*fd < 0) return 0;
    int n = *fd; *fd = -1; /* Linux: never retry the descriptor number. */
    return close(n) == 0 ? 0 : perr("close", errno);
}
static int one_thread(const char *stage) {
    DIR *d = opendir("/proc/self/task");
    if (!d) return perr("opendir task", errno);
    int count = 0, saved = 0;
    struct dirent *e;
    errno = 0;
    while ((e = readdir(d))) if (e->d_name[0] != '.') ++count;
    saved = errno;
    if (closedir(d) != 0) return perr("closedir task", errno);
    if (saved) return perr("readdir task", saved);
    printf("THREADS stage=%s count=%d\n", stage, count);
    return count == 1 ? 0 : perr("single-thread prerequisite", EINVAL);
}
/* The declared business contract permits discarding the entire mailbox. */
static void empty(Mailbox *b) { memset(b, 0, sizeof *b); }
static int is_empty(const Mailbox *b) {
    if (b->length != 0) return 0;
    for (size_t i = 0; i < CAP; ++i) if (b->bytes[i] != 0) return 0;
    return 1;
}
int main(int argc, char **argv) {
    if (argc != 2 || (strcmp(argv[1], "normal") &&
        strcmp(argv[1], "repair") && strcmp(argv[1], "poison"))) {
        fprintf(stderr, "usage: %s normal|repair|poison\n", argv[0]);
        return 2;
    }
    if (setvbuf(stdout, NULL, _IONBF, 0) != 0) return 1;
    if (one_thread("entry") != 0) return 1;
    struct sigaction sa = {0};
    sa.sa_handler = SIG_DFL; /* Clear inherited SIG_IGN / SA_NOCLDWAIT. */
    if (sigemptyset(&sa.sa_mask) != 0 || sigaction(SIGCHLD, &sa, NULL) != 0) {
        perr("SIGCHLD disposition", errno); return 1;
    }
    int normal = !strcmp(argv[1], "normal"), poison = !strcmp(argv[1], "poison");
    int fd = -1, attr_live = 0, mutex_live = 0, rc = 1, e;
    int child_created = 0, reaped = 0, held = 0, safe_retire = 1;
    void *mapping = MAP_FAILED;
    Shared *s = NULL;
    pthread_mutexattr_t attr;
    pid_t child = -1;
    char name[80];
    int nn = snprintf(name, sizeof name, "/ipc05-%ld-%s", (long)getpid(), argv[1]);
    if (nn < 0 || (size_t)nn >= sizeof name) return 1;
    /* Linux off_t conversion must round-trip before any size-dependent API. */
    off_t length = (off_t)sizeof(Shared);
    if (length <= 0 || (uintmax_t)length != (uintmax_t)sizeof(Shared)) return 1;
    fd = shm_open(name, O_CREAT | O_EXCL | O_RDWR, 0600);
    if (fd < 0) { perr("shm_open: existing names are untouched", errno); goto cleanup; }
    printf("NAME %s\n", name);
    if (shm_unlink(name) != 0) {
        perr("first unlink failed; possible residual name; no retry", errno);
        goto cleanup;
    }
    puts("UNLINK success; no further name-based cleanup");
    if (ftruncate(fd, length) != 0) { perr("ftruncate", errno); goto cleanup; }
    mapping = mmap(NULL, sizeof(Shared), PROT_READ | PROT_WRITE, MAP_SHARED, fd, 0);
    if (mapping == MAP_FAILED) { perr("mmap", errno); goto cleanup; }
    if ((uintptr_t)mapping % _Alignof(Shared) != 0) {
        perr("natural alignment", EINVAL); goto cleanup;
    }
    s = mapping; /* Convert only after checking alignment. */
    if ((e = pthread_mutexattr_init(&attr))) { perr("attr init", e); goto cleanup; }
    attr_live = 1;
    if ((e = pthread_mutexattr_setpshared(&attr, PTHREAD_PROCESS_SHARED))) {
        perr("setpshared", e); goto cleanup;
    }
    if ((e = pthread_mutexattr_setrobust(&attr, PTHREAD_MUTEX_ROBUST))) {
        perr("setrobust", e); goto cleanup;
    }
    if ((e = pthread_mutex_init(&s->mutex, &attr))) {
        perr("mutex init", e); goto cleanup;
    }
    mutex_live = 1;
    empty(&s->box);
    e = pthread_mutexattr_destroy(&attr); attr_live = 0;
    if (e) { perr("attr destroy", e); goto cleanup; }
    if (close_once(&fd) != 0 || one_thread("prefork") != 0) goto cleanup;
    child = fork();
    if (child < 0) { perr("fork", errno); goto cleanup; }
    if (child == 0) {
        e = pthread_mutex_lock(&s->mutex);
        if (e != 0) { perr("child lock", e); _exit(CHILD_FAILED); }
        if (normal) {
            memcpy(s->box.bytes, "ping", 4);
            s->box.length = 4;
            e = pthread_mutex_unlock(&s->mutex);
            if (e) { perr("child unlock", e); _exit(CHILD_FAILED); }
            _exit(CHILD_OK);
        }
        s->box.bytes[0] = 'x';
        s->box.length = CAP + 1; /* A damaged value, never an out-of-bounds access. */
        _exit(CHILD_INJECTED); /* Keep mapping and held mutex for robust exit. */
    }
    child_created = 1; safe_retire = 0;
    printf("CHILD_PID %ld\n", (long)child);
    int status = 0;
    pid_t w;
    do { w = waitpid(child, &status, 0); } while (w < 0 && errno == EINTR);
    if (w != child) { perr("waitpid", errno); goto preserve; }
    reaped = 1;
    if (!WIFEXITED(status)) { perr("child did not exit normally", ECHILD); goto preserve; }
    printf("REAP child=%ld exit=%d\n", (long)child, WEXITSTATUS(status));
    if (WEXITSTATUS(status) != (normal ? CHILD_OK : CHILD_INJECTED)) {
        perr("unexpected child exit", ECHILD); goto preserve;
    }
    e = pthread_mutex_lock(&s->mutex);
    held = (e == 0 || e == EOWNERDEAD);
    printf("LOCK1 code=%d expected=%d held=%d\n", e, normal ? 0 : EOWNERDEAD, held);
    if (e != (normal ? 0 : EOWNERDEAD)) goto preserve;
    if (normal) {
        if (s->box.length != 4 || memcmp(s->box.bytes, "ping", 4) != 0) goto preserve;
        empty(&s->box);
    } else if (!poison) {
        empty(&s->box); /* Discard only business state, never the mutex. */
        if (!is_empty(&s->box)) goto preserve;
        if ((e = pthread_mutex_consistent(&s->mutex))) {
            perr("consistent", e); goto preserve;
        }
    }
    if ((e = pthread_mutex_unlock(&s->mutex))) { perr("unlock1", e); goto preserve; }
    held = 0;
    e = pthread_mutex_lock(&s->mutex);
    held = (e == 0 || e == EOWNERDEAD);
    printf("LOCK2 code=%d expected=%d held=%d\n", e, poison ? ENOTRECOVERABLE : 0, held);
    if (poison) {
        if (e != ENOTRECOVERABLE) goto preserve;
        /* ENOTRECOVERABLE did not grant ownership: no unlock here. */
    } else {
        if (e != 0 || !is_empty(&s->box)) goto preserve;
        if ((e = pthread_mutex_unlock(&s->mutex))) { perr("unlock2", e); goto preserve; }
        held = 0;
    }
    safe_retire = 1; rc = 0;
cleanup:
    if (attr_live) {
        e = pthread_mutexattr_destroy(&attr); attr_live = 0;
        if (e) { perr("cleanup attr destroy", e); rc = 1; }
    }
    if (mutex_live) {
        if (!safe_retire || held || (child_created && !reaped)) goto preserve;
        e = pthread_mutex_destroy(&s->mutex);
        if (e) { perr("mutex destroy; mapping retained", e); goto preserve; }
        mutex_live = 0;
    }
    if (mapping != MAP_FAILED && munmap(mapping, sizeof(Shared)) != 0) {
        perr("munmap", errno); rc = 1;
    }
    if (close_once(&fd) != 0) rc = 1;
    if (rc == 0) printf("PASS %s child_reaped=1 mutex_destroyed=1 unmapped=1 fd_closed=1\n", argv[1]);
    return rc;
preserve:
    fprintf(stderr, "FAIL: retained mapping until process exit; held=%d child_created=%d reaped=%d\n",
            held, child_created, reaped);
    (void)close_once(&fd);
    return 1;
}
```

唯一创建者假定隔离练习期间没有同 UID 程序换掉其名字；0600 不防恶意同 UID 竞争。EEXIST 不删、不截断别人的对象。首次 unlink 失败后只关自己的 fd 并报可能残留；成功 unlink 后绝不再按原名字删除，因为新名字可能已指另一代对象。

normal 的顺序是 child 写 ping 并解锁 → 精确 waitpid 回收 → parent lock 验证/消费 → 再 lock 验证空态。repair 则是 child 持锁写坏长度并保留映射 `_exit(21)` → parent 确认这一退出码 → EOWNERDEAD 已获锁 → 清空 mailbox → consistent/unlock → 再 lock=0。poison 在 fresh 对象上明确拒修，unlock 后 lock=ENOTRECOVERABLE，此时没有锁可以解。[wait(2)](https://man7.org/linux/man-pages/man2/waitpid.2.html)证明 child 不再使用对象，不能代替 parent 通过 mutex 读取数据。

持锁 child 不得先 munmap 再退出：Linux 退出清理要访问用户态 robust 链，失效地址会中断扫描。见 [robust futex ABI](https://www.kernel.org/doc/html/latest/locking/robust-futex-ABI.html)。因此 child 的失败/注入路径直接退出，映射保留；parent 的 unexpected lock、consistent、unlock、退出码或回收错误也不盲目 destroy/unmap，非零退出时保留可能仍在 robust 链中的地址。这是独立练习的受控失败边界，不是库函数的通用恢复策略。

| 失败阶段 | 已有资源及收尾边界 |
| --- | --- |
| 创建 / unlink / 定长 / 映射失败 | 只释放实际获得的 fd 或映射；不 destroy 未初始化对象；名字不循环清理 |
| attr 初始化 / setter / mutex 初始化失败 | 按 attr_live、mutex_live 分开处理，不 fork |
| attr 销毁 / close / fork 失败 | 没有 child 且 mutex 未持有时可销毁；清理错误仍使结果失败 |
| child 异常或 parent 未确认回收 | 不宣称业务恢复或对象安全退役；保留映射失败退出，监督另查进程状态 |
| parent 已确认拥有锁但数据不符 / consistent 或 unlock 失败 | 停止业务，保留映射到进程结束；不能覆盖 mutex 或假定已解锁 |
| 无人使用且明确解锁 / ENOTRECOVERABLE | 唯一 parent 可 destroy 再 munmap；错误不能打印收尾 PASS |

正常回收条件是已初始化、已确认无持有者/等待者且 child 已回收。见 [pthread_mutex_destroy(3p)](https://man7.org/linux/man-pages/man3/pthread_mutex_destroy.3p.html) 的销毁合同；它是 man7 的 POSIX.1-2017 授权重印，不是本次访问成功的 OpenGroup 原站。Linux [close(2)](https://man7.org/linux/man-pages/man2/close.2.html) 出错后不盲重试 fd 数字，避免关掉已复用的槽。

## 3. SPSC：两条顺序边与跨进程前提

原环形模板的教学价值是槽位的发布与回收，而“完整工业级跨进程实现”缺少对象创建、初始化发布、ABI 和崩溃合同。这里用容量 2 的追踪说明机制，不再提供另一版无锁算法：

| 步骤 | producer | consumer | 为什么安全或为何需等待 |
| --- | --- | --- | --- |
| 初始 | head=0、tail=0 | 无可读项 | 槽位对象已建立生存期且唯一初始化完成 |
| 发布槽 0 | 写槽 0；release store tail=1 | acquire load tail 读到 1 后读槽 0 | 第一条边把 payload 写入排在读取之前 |
| 回收槽 0 | 尚不能据旧 head 复用满环槽位 | 读完槽 0；release store head=1 | 第二条边宣布此前读取完成 |
| 复用 | acquire load head 读到 1 后才覆写获释放槽位 | 继续消费下一项 | 避免 producer 的新写与 consumer 的旧读重叠 |

只有 tail 的 release/acquire 不够：若消费者提早发布 head，生产者可能覆写尚未读完的槽位。两端各自的游标通常可 relaxed 读取，但用于观察对方发布/回收的读取不能随意降级。这个时序推导依赖实际读取相应发布值与算法不变量，不是“随便写两个 acquire 就安全”。

掩码索引要求 `Capacity > 0` 且为 2 的幂；旧 `(Capacity & (Capacity-1))==0` 会放过零。无符号游标按位宽取模仍须证明在途数不超过容量、容量小于游标模空间、模差可区分空与满；不能用有符号溢出或无限落后假定回绕正确。槽位类型还须有明确构造/析构责任和固定表示；任意 T 的指针、虚表、异常赋值、所有权都不会被 `noexcept` 变安全。

C++20 草案 [N4861 §31.5 [atomics.lockfree] p5](https://www.open-std.org/jtc1/sc22/wg21/docs/papers/2020/n4861.pdf) 位于印刷页 1526（PDF 零基页 1533）：address-free 出现在非规范性 Note 中，用的是 should。`is_lock_free()` 不等于已获得跨进程、不同映射地址或混合 ABI 的可移植保证。独立进程还需具体编译器/标准库/CPU 的支持合同、兼容布局、统一初始化与原子/槽位的对象生存期。64 字节对齐只是布局选择，既非所有平台缓存线事实，也不证明槽位没有伪共享。

producer 在写 payload 后、发布 tail 前死亡，或 consumer 读 payload 后、回收 head 前死亡，会分别留下未发布状态、可能重复处理或卡住的槽位；两个原子索引没有业务提交日志。上述 SPSC 为 PAPER_EXPECTED 机制分析，未运行跨进程原子测试，未作崩溃恢复与吞吐量承诺。需要可解释的丢弃恢复时，可先用第 2 节的有限 mutex 合同。

## 4. FD passing：引用交付与业务接管分开

SCM_RIGHTS 在接收进程安装指向同一 open file description 的引用，数字通常不同；它不是把发送端 fd 数字复制过去，也不自动关掉发送端引用。共享的文件偏移和状态标志要按资源类型考虑。Unix 系统也有 SCM_RIGHTS，它不是 Linux 独有；本练习使用的具体标志与行为按 Linux 文档限定。

### 4.1 完整接收合同

固定同二进制可信父子，新建专用 `AF_UNIX/SOCK_SEQPACKET` socketpair，只保留默认 ancillary 配置；不启用额外 descriptor-bearing 控制扩展，不与其他接收线程共享 socket。合法记录是一字节 F 加一个 FD。control 用含 cmsghdr 的 union 对齐，容量用 CMSG_SPACE、头长用 CMSG_LEN、数据用 memcpy。`sendmsg` 精确传出整条记录才算发送成功；非负短返回不能盲重发以免重复交付。EINTR 可重试，EAGAIN/EWOULDBLOCK 在本例直接报告超时/背压失败。

每个 `recvmsg >= 0` 的结果，包括断连的 0，都先遍历合法范围中的全部 SCM_RIGHTS，再综合判定标记、长度、TRUNC/CTRUNC、未知 cmsg 和 FD 数量。协议错误先积累，不能提前 return 丢掉已安装引用。“一 FD 大小”的 control 可能因 padding 容下第二 FD，必须按实际 cmsg_len 清点。CTRUNC 时内核关闭没能返回的多余 FD，应用仍须关闭已经返回的全部 FD。[cmsg(3)](https://man7.org/linux/man-pages/man3/cmsg.3.html)、[recv(2)](https://man7.org/linux/man-pages/man2/recvmsg.2.html) 和 [unix(7)](https://man7.org/linux/man-pages/man7/unix.7.html)支持这些 API 边界。

以下 `fd_delivery.c` 保留一个活 receiver，连续执行 8 轮正例与五种拒收，再测试断连。每次都比对 receiver 自己的 FD 数，排除枚举目录本身的 fd，避免 `_exit` 自动关闭掩盖泄漏。每个非负接收都打印实际 flags、可见 FD 数和 FD_CLOEXEC 检查结果；只有观测到标志才可说截断分支已运行。

pipe 在 fork 后由 parent 创建；parent 保留读端时先写 K、关写端，再传读端。child 只能通过收到的 FD 读到 K，并用 fstat 验证其为 FIFO。MSG_NOSIGNAL 只保护 socket send，不保护 pipe write；这个顺序避免负例接收端提前关闭导致无关 SIGPIPE。ACK 只证明本练习已读取/拒收，不证明业务接管。

```c
/* fd_delivery.c: Linux-only, dedicated default-ancillary SOCK_SEQPACKET. */
#define _GNU_SOURCE
#include <dirent.h>
#include <errno.h>
#include <fcntl.h>
#include <signal.h>
#include <stddef.h>
#include <stdio.h>
#include <stdlib.h>
#include <string.h>
#include <sys/socket.h>
#include <sys/stat.h>
#include <sys/time.h>
#include <sys/types.h>
#include <sys/wait.h>
#include <unistd.h>

enum { ROUNDS = 8, CASES = 6, MAX_SEND = 8, CHILD_OK = 20, CHILD_FAIL = 90 };
static const char *cases[CASES] = {"one", "zero", "two", "bad_marker", "payload_trunc", "control_trunc"};
static int error(const char *what) { perror(what); return -1; }
static int close_once(int *p) {
    if (*p < 0) return 0;
    int n = *p; *p = -1;
    return close(n) == 0 ? 0 : error("close (not retried)");
}
/* Exclude the enumerator's descriptor. No other thread mutates the fd table. */
static int count_fds(void) {
    DIR *d = opendir("/proc/self/fd");
    if (!d) return error("opendir fd");
    int own = dirfd(d), count = 0, saved;
    if (own < 0) {
        int e = errno;
        if (closedir(d) != 0) error("closedir after dirfd failure");
        errno = e; return error("dirfd");
    }
    struct dirent *e;
    errno = 0;
    while ((e = readdir(d))) {
        char *end;
        if (e->d_name[0] == '.') continue;
        long fd = strtol(e->d_name, &end, 10);
        if (*end == '\0' && fd >= 0 && fd != own) ++count;
    }
    saved = errno;
    if (closedir(d) != 0) return error("closedir fd");
    if (saved) { errno = saved; return error("readdir fd"); }
    return count;
}
static int one_thread(void) {
    DIR *d = opendir("/proc/self/task");
    if (!d) return error("opendir task");
    int n = 0, saved;
    struct dirent *e;
    errno = 0;
    while ((e = readdir(d))) if (e->d_name[0] != '.') ++n;
    saved = errno;
    if (closedir(d) != 0) return error("closedir task");
    if (saved) { errno = saved; return error("readdir task"); }
    printf("THREADS prefork=%d\n", n);
    return n == 1 ? 0 : -1;
}
static int configure(int fd) {
    struct timeval tv = {.tv_sec = 2, .tv_usec = 0};
    if (setsockopt(fd, SOL_SOCKET, SO_RCVTIMEO, &tv, sizeof tv) != 0 ||
        setsockopt(fd, SOL_SOCKET, SO_SNDTIMEO, &tv, sizeof tv) != 0)
        return error("socket timeout");
    return 0;
}
static int send_record(int sock, int resource, int kind) {
    union { struct cmsghdr align; unsigned char bytes[CMSG_SPACE(MAX_SEND * sizeof(int))]; } u = {0};
    int fds[MAX_SEND];
    size_t nf = kind == 1 ? 0 : kind == 2 ? 2 : kind == 5 ? MAX_SEND : 1;
    for (size_t i = 0; i < nf; ++i) fds[i] = resource;
    char payload[2] = {kind == 3 ? 'X' : 'F', 'Z'};
    struct iovec iov = {.iov_base = payload, .iov_len = kind == 4 ? 2 : 1};
    struct msghdr m = {0};
    m.msg_iov = &iov; m.msg_iovlen = 1;
    if (nf) {
        m.msg_control = u.bytes; m.msg_controllen = CMSG_SPACE(nf * sizeof(int));
        struct cmsghdr *h = CMSG_FIRSTHDR(&m);
        h->cmsg_level = SOL_SOCKET; h->cmsg_type = SCM_RIGHTS;
        h->cmsg_len = CMSG_LEN(nf * sizeof(int));
        memcpy(CMSG_DATA(h), fds, nf * sizeof(int));
    }
    ssize_t n;
    do { n = sendmsg(sock, &m, MSG_NOSIGNAL); } while (n < 0 && errno == EINTR);
    if (n < 0) {
        if (errno == EAGAIN || errno == EWOULDBLOCK) return error("sendmsg timeout/backpressure");
        return error("sendmsg");
    }
    if ((size_t)n != iov.iov_len) { fprintf(stderr, "short record: no retry\n"); return -1; }
    return 0;
}
/* Return 1 and transfer exactly one fd, 0 for rejected record, -1 for API/cleanup failure. */
static int receive_one(int sock, int *out, ssize_t *bytes, int *flags, size_t *seen) {
    union { struct cmsghdr align; unsigned char bytes[CMSG_SPACE(sizeof(int))]; } u;
    int got[sizeof u.bytes / sizeof(int)];
    size_t count = 0;
    int bad = 0, cleanup_failed = 0, all_cloexec = 1;
    char marker = 0;
    struct msghdr m;
    struct iovec iov;
    ssize_t n;
    *out = -1;
    for (;;) {
        memset(&u, 0, sizeof u); memset(&m, 0, sizeof m);
        iov.iov_base = &marker; iov.iov_len = 1;
        m.msg_iov = &iov; m.msg_iovlen = 1;
        m.msg_control = u.bytes; m.msg_controllen = sizeof u.bytes;
        n = recvmsg(sock, &m, MSG_CMSG_CLOEXEC);
        if (n < 0 && errno == EINTR) continue;
        if (n < 0) {
            if (errno == EAGAIN || errno == EWOULDBLOCK) return error("recvmsg timeout/no record");
            return error("recvmsg");
        }
        break;
    }
    /* No payload/flag error can return before safely visible rights are inventoried. */
    if (m.msg_controllen > sizeof u.bytes) { bad = 1; m.msg_controllen = sizeof u.bytes; }
    unsigned char *end = u.bytes + m.msg_controllen;
    for (struct cmsghdr *h = CMSG_FIRSTHDR(&m); h; h = CMSG_NXTHDR(&m, h)) {
        unsigned char *p = (unsigned char *)h;
        if (p < u.bytes || p > end || (size_t)(end - p) < sizeof *h) { bad = 1; break; }
        if (h->cmsg_len < CMSG_LEN(0) || h->cmsg_len > (size_t)(end - p)) { bad = 1; break; }
        if (h->cmsg_level != SOL_SOCKET || h->cmsg_type != SCM_RIGHTS) { bad = 1; continue; }
        size_t data = h->cmsg_len - CMSG_LEN(0);
        if (data % sizeof(int)) bad = 1;
        for (size_t off = 0; off + sizeof(int) <= data; off += sizeof(int)) {
            int fd;
            memcpy(&fd, (unsigned char *)CMSG_DATA(h) + off, sizeof fd);
            /* Capacity covers all ints the complete control buffer could contain. */
            if (count < sizeof got / sizeof got[0]) got[count++] = fd;
            else { bad = 1; if (close_once(&fd) != 0) cleanup_failed = 1; }
        }
    }
    for (size_t i = 0; i < count; ++i) {
        int f = fcntl(got[i], F_GETFD);
        if (f < 0 || !(f & FD_CLOEXEC)) { bad = 1; all_cloexec = 0; }
    }
    if (n != 1 || marker != 'F' || (m.msg_flags & (MSG_TRUNC | MSG_CTRUNC)) || count != 1) bad = 1;
    *bytes = n; *flags = m.msg_flags; *seen = count;
    printf("RECV bytes=%zd flags=%d visible_fds=%zu cloexec=%d accepted=%d\n",
           n, m.msg_flags, count, all_cloexec, !bad);
    if (bad) {
        for (size_t i = 0; i < count; ++i) if (close_once(&got[i]) != 0) cleanup_failed = 1;
        return cleanup_failed ? -1 : 0;
    }
    *out = got[0];
    return 1;
}
static int ack(int sock, char value) {
    ssize_t n;
    do { n = send(sock, &value, 1, MSG_NOSIGNAL); } while (n < 0 && errno == EINTR);
    if (n < 0) return error("ACK send");
    if (n != 1) { fprintf(stderr, "short ACK: no retry\n"); return -1; }
    return 0;
}
static int receiver(int sock) {
    int baseline = count_fds();
    if (baseline < 0) return 1;
    for (int round = 0; round < ROUNDS; ++round) {
        for (int kind = 0; kind < CASES; ++kind) {
            int before = count_fds();
            if (before != baseline) return 1;
            int fd = -1, flags = 0;
            ssize_t bytes = -1;
            size_t seen = 0;
            int r = receive_one(sock, &fd, &bytes, &flags, &seen);
            int ok = r == (kind == 0 ? 1 : 0);
            if (kind == 4 && !(flags & MSG_TRUNC)) ok = 0;
            if (kind == 5 && !(flags & MSG_CTRUNC)) ok = 0;
            if (r == 1) {
                struct stat st;
                char ch = 0;
                if (fstat(fd, &st) != 0 || !S_ISFIFO(st.st_mode)) ok = 0;
                if (ok) {
                    ssize_t n;
                    do { n = read(fd, &ch, 1); } while (n < 0 && errno == EINTR);
                    if (n != 1 || ch != 'K') ok = 0;
                }
                if (close_once(&fd) != 0) ok = 0;
            }
            int after = count_fds();
            printf("CASE round=%d kind=%s fd_before=%d fd_after=%d\n", round, cases[kind], before, after);
            if (!ok || after != baseline) return 1;
            if (ack(sock, kind == 0 ? 'A' : 'R') != 0) return 1;
        }
    }
    int fd = -1, flags = 0;
    ssize_t bytes = -1;
    size_t seen = 0;
    int r = receive_one(sock, &fd, &bytes, &flags, &seen);
    if (fd >= 0 && close_once(&fd) != 0) return 1;
    if (r != 0 || bytes != 0 || seen != 0 || count_fds() != baseline) return 1;
    puts("DISCONNECT rejected; live receiver fd count restored");
    return 0;
}
int main(void) {
    if (setvbuf(stdout, NULL, _IONBF, 0) != 0 || one_thread() != 0) return 1;
    struct sigaction sa = {0}; sa.sa_handler = SIG_DFL;
    if (sigemptyset(&sa.sa_mask) != 0 || sigaction(SIGCHLD, &sa, NULL) != 0) return 1;
    int sv[2] = {-1, -1}, failed = 0;
    if (socketpair(AF_UNIX, SOCK_SEQPACKET | SOCK_CLOEXEC, 0, sv) != 0) {
        error("socketpair"); return 1;
    }
    if (configure(sv[0]) != 0 || configure(sv[1]) != 0) { failed = 1; goto no_child; }
    pid_t child = fork();
    if (child < 0) { error("fork"); failed = 1; goto no_child; }
    if (child == 0) {
        if (close_once(&sv[0]) != 0) _exit(CHILD_FAIL);
        int r = receiver(sv[1]);
        if (close_once(&sv[1]) != 0) r = 1;
        _exit(r ? CHILD_FAIL : CHILD_OK);
    }
    printf("CHILD_PID %ld\n", (long)child);
    if (close_once(&sv[1]) != 0) failed = 1;
    for (int round = 0; round < ROUNDS && !failed; ++round) {
        for (int kind = 0; kind < CASES && !failed; ++kind) {
            int p[2] = {-1, -1};
            if (pipe2(p, O_CLOEXEC) != 0) { error("pipe2"); failed = 1; break; }
            char ch = 'K';
            ssize_t n;
            do { n = write(p[1], &ch, 1); } while (n < 0 && errno == EINTR);
            if (n != 1) { error("pipe write"); failed = 1; }
            if (close_once(&p[1]) != 0) failed = 1;
            if (!failed && send_record(sv[0], p[0], kind) != 0) failed = 1;
            if (close_once(&p[0]) != 0) failed = 1;
            if (!failed) {
                char reply[2] = {0};
                do { n = recv(sv[0], reply, sizeof reply, 0); } while (n < 0 && errno == EINTR);
                if (n != 1 || reply[0] != (kind == 0 ? 'A' : 'R')) failed = 1;
            }
        }
    }
    if (close_once(&sv[0]) != 0) failed = 1;
    int status = 0;
    pid_t w;
    do { w = waitpid(child, &status, 0); } while (w < 0 && errno == EINTR);
    if (w != child) { error("waitpid"); failed = 1; }
    else if (!WIFEXITED(status)) { fprintf(stderr, "child did not exit normally\n"); failed = 1; }
    else {
        printf("REAP child=%ld exit=%d\n", (long)child, WEXITSTATUS(status));
        if (WEXITSTATUS(status) != CHILD_OK) failed = 1;
    }
    if (!failed) printf("PASS fd_delivery records=%d child_reaped=1 endpoints_closed=1\n", ROUNDS * CASES);
no_child:
    if (close_once(&sv[0]) != 0) failed = 1;
    if (close_once(&sv[1]) != 0) failed = 1;
    return failed ? 1 : 0;
}
```

拒收只释放安全清点出来的引用；如果控制布局损坏到无法定位下一个头，停止遍历，不扫描任意整数猜 fd。这里处理 Linux 内核生成的合法 control 序列及有限输入，不承诺内存被破坏、未知含句柄扩展或恶意内核下仍全回收。发送端畸形 cmsg 可能在 sendmsg 已被拒绝或规范化，本轮没有伪造任意接收头长，也没有把“未知 cmsg 防御分支存在”说成已跑到。

系统调用失败、ACK 不符、CLOEXEC 不符、实际 FD 数未恢复或未观测预期截断 flag 都失败；receiver 异常会以不同码退出，parent 关闭自己的端点后精确 waitpid。SO_RCVTIMEO/SO_SNDTIMEO 让无响应转为失败，但不构成硬实时上界；外层监督仍需覆盖异常挂起。每个本地资源槽 close 一次；若 close 返回错误，不能同时声称全部清理完成。正例收到唯一 fd 后，调用者验证资源用途、读 K、close，才 ACK；拒收后所有可见 fd 先 close，才发拒收 ACK。

### 4.2 热替换还缺什么

```text
旧进程暂停目标连接业务 I/O，保留原引用与待迁移用户态状态
    -> 经控制协议交付 FD -> 新进程校验引用及应用状态
    -> 明确接管点 -> ACK -> 按合同关闭旧引用
失败在发送前：旧进程仍负责
失败在接收拒收：接收侧关闭所有可见引用，旧进程按合同处置
失败在接管后但 ACK 丢失：双方归属不确定，不能各自猜测重试读写
无法定义这些状态：旧连接留旧进程排空，新进程只接新连接
```

TCP FD 不会带走 TLS、用户态收发/解码缓冲、会话状态和定时器。一个 FD 加 ACK 只提供资源引用交付证据；业务是否无感取决于更完整的协议。本篇没有实现在线玩家迁移，也没有测试零停机或连接容量。

## 5. eventfd：先消费通知，再检查数据谓词

非 EFD_SEMAPHORE 的 eventfd 读出当前累计值并清零；非阻塞空读得到 EAGAIN。写入是加法，最大计数是 UINT64_MAX-1，写 UINT64_MAX 非法；会超过最大值的非阻塞写得到 EAGAIN。成功读写本例要求恰好 8 字节。fork 继承同一事件对象的引用；EFD_CLOEXEC 的意义是 exec 时关闭，最后引用关闭才回收。计数器字段是 64 位，不表示内核对象总成本只有 8 字节。[eventfd(2)](https://man7.org/linux/man-pages/man2/eventfd.2.html) 是这些 API 语义的来源。

### 5.1 通知协议的可追踪顺序

下面是作者设计推导，限定同一 eventfd、一个消费者、非 semaphore 模式，以及已经成立的共享数据 mutex 合同。多消费者、EPOLLET/ONESHOT、工作窃取均不在此合同内。poll/epoll 的可读状态让事件加入循环，但不自动建立业务同步。

1. producer 持锁验证并提交数据，成功解锁后向 eventfd 写固定 uint64_t 1。EINTR 可重试；饱和 EAGAIN 时该事件对象已有非零通知，可合并这次提醒，不忙等补计数，不重放 payload。此处“可合并”是这个顺序及 readiness 语义下的设计结论，不是内核保证业务已成功
2. consumer 先非阻塞读一次通知。读成功会清零；EAGAIN 只表示此刻没通知，仍执行下一步。无限 drain 可能在持续通知下不终止，此有限非 semaphore 例不需要它
3. consumer 持既定 mutex 检查数据谓词、验证/取走有限数据或处理明确恢复状态，再解锁。有工作需继续时回到循环；只有最终持锁确认空，才进入有限 poll，而且判空之后不能再清 eventfd
4. poll 到期或 EINTR 后重新检查谓词及约定的 peer 生存状态；错误 flags、不可恢复 mutex 或其他通知错误停止该通道。超时提供回查机会，不是硬实时保证，也不能解决活 owner 永久持锁

为什么不会把新通知随手清掉：若 producer 在 consumer 消费通知之前发布，consumer 随后的锁内检查读到数据；若 producer 在 consumer 最终判空之后发布，其通知留在 eventfd，后续等待立即或随后可醒。反向顺序则有明确丢唤醒反例：

```text
C：持锁判空 -> 解锁
P：持锁提交数据 -> 解锁 -> write(eventfd, 1)
C：read(eventfd) 清零 -> 无期限 poll
结果：数据仍在，但唯一通知已被 C 在最后一次检查之后清掉
```

另一个边界是 producer 已提交并解锁，尚未通知就退出。robust 只识别持锁 owner 死亡，已解锁不会报告这个窗口。有限周期回查或可信死亡通道必须触发谓词检查；不能仅靠永久等待 doorbell。可丢弃 mailbox 的恢复合同也不能推成持久队列的 exactly-once。以上时序是 PAPER_EXPECTED，未运行真实 queue 通知协议或非法 race。

### 5.2 完整有限 API 练习

`event_counter.c` 只检查计数 API：2+3→5、空读、饱和 EAGAIN、读后恢复及非法 UINT64_MAX。它不含共享 queue 或跨进程 producer，不能用它的通过代替上一节的协议验证。

```c
/* event_counter.c: Linux, nonblocking, non-semaphore, one consumer. */
#define _GNU_SOURCE
#include <errno.h>
#include <inttypes.h>
#include <stdint.h>
#include <stdio.h>
#include <sys/eventfd.h>
#include <unistd.h>

static int put(int fd, uint64_t value, int expected_errno) {
    ssize_t n;
    do { n = write(fd, &value, sizeof value); } while (n < 0 && errno == EINTR);
    int e = n < 0 ? errno : 0;
    printf("WRITE value=%" PRIu64 " bytes=%zd errno=%d\n", value, n, e);
    if (expected_errno) return n == -1 && e == expected_errno ? 0 : -1;
    return n == (ssize_t)sizeof value ? 0 : -1;
}
static int take(int fd, uint64_t expected_value, int expected_errno) {
    uint64_t value = 0;
    ssize_t n;
    do { n = read(fd, &value, sizeof value); } while (n < 0 && errno == EINTR);
    int e = n < 0 ? errno : 0;
    printf("READ value=%" PRIu64 " bytes=%zd errno=%d\n", value, n, e);
    if (expected_errno) return n == -1 && e == expected_errno ? 0 : -1;
    return n == (ssize_t)sizeof value && value == expected_value ? 0 : -1;
}
int main(void) {
    int fd = eventfd(0, EFD_NONBLOCK | EFD_CLOEXEC);
    if (fd < 0) { perror("eventfd"); return 1; }
    int failed = 0;
    if (put(fd, 2, 0) || put(fd, 3, 0) || take(fd, 5, 0) || take(fd, 0, EAGAIN) ||
        put(fd, UINT64_MAX - 1, 0) || put(fd, 1, EAGAIN) ||
        take(fd, UINT64_MAX - 1, 0) || put(fd, 1, 0) || take(fd, 1, 0) ||
        put(fd, UINT64_MAX, EINVAL) || take(fd, 0, EAGAIN)) failed = 1;
    if (close(fd) != 0) { perror("close (not retried)"); failed = 1; }
    if (!failed) puts("PASS event_counter closed=1");
    return failed ? 1 : 0;
}
```
