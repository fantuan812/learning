## 分类边界

- A*/NavMesh的算法归数学算法；智能体决策与路径跟随归AI；服务端查询预算归网络服务端
- 碰撞数学归算法；物理求解和动画求值归仿真；命中和伤害规则归Gameplay
- C++所有权归编程基础；UObject GC归引擎；如何测量与验证归工程质量
- 背包和活动的业务规则归Gameplay；跨进程事务、权威与恢复归网络服务端
- 资源运行时加载归引擎；Cook、构建产物、发布验收归工程质量
- 大型源码解析与端到端案例保留完整叙事，选一个主域，并链接其他主责概念

来源、技术栈、内容类型互相独立：UE是技术栈，官方文档是来源，源码解析是内容类型。实验通过只证明实际执行的范围，不自动提升文档成熟度。
