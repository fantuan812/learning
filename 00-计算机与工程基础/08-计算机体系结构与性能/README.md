## 2. 逻辑学习顺序与依赖关系

```text
01. 存储层次与缓存协议 (01-处理器存储层次与性能工程.md)
  └─→ 02. 指令集、汇编与调用规范 (03-ISA汇编与调用约定.md)
        └─→ 03. 编译器优化与 SIMD 并行 (04-编译器优化与GPU异构.md)
              └─→ 04. 硬件辅助虚拟化与隔离 (05-虚拟化与硬件辅助隔离.md)
```

1. **第一阶段：掌控数据流动瓶颈——存储层次**：研读 [01-处理器存储层次与性能工程](01-处理器存储层次与性能工程.md)，牢记 L1（~1ns）、L2（~4ns）、L3（~10ns）、DRAM（~60-100ns）的巨大时延级差，掌握面向数据设计（DOD）的物理根基。
2. **第二阶段：打通汇编与调用约定**：研读 [03-ISA汇编与调用约定](03-ISA汇编与调用约定.md)，能够阅读反汇编确认编译器是否将局部变量放入寄存器，掌握函数调用参数传递与栈平衡。
3. **第三阶段：发挥指令级与向量级并行**：研读 [04-编译器优化与GPU异构](04-编译器优化与GPU异构.md)，学会使用 SIMD Intrinsics 一条指令处理 4~8 个浮点数（如 3D 向量变换）。
4. **第四阶段：理解云端运行基石**：研读 [05-虚拟化与硬件辅助隔离](05-虚拟化与硬件辅助隔离.md)，理解云原生游戏服务器部署中物理核绑定与避免虚拟机过度超售的必要性。

## 3. 游戏研发与工程落地对接

- **Unreal Engine (UE5)**：
  - UE 渲染管线与几何数学计算（`FVector`、`FMatrix`）：深度依赖 SSE/AVX2/NEON 向量指令集优化；
  - Unreal Build Tool (UBT) 的代码内联策略与链接期优化（LTO / LTCG）；
  - Nanite 与 Lumen 计算着色器调度：理解 GPU 线程束（Warp/Wavefront）分歧（Divergence）对帧时间的影响。
- **游戏服务端与引擎底层**：
  - 为什么循环数组（Flat Array）遍历比指针跳跃快数十倍：硬件预取器（L2 Stream Prefetcher）只能识别线性或固定步长内存访问；
  - NUMA 亲和性：在多路双路服务器上，将网卡中断处理与网络进程绑定在同一个 NUMA 节点，避免跨 UPI/QPI 总线内存访问引入 40ns+ 延迟。
