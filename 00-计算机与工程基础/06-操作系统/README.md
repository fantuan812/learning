```text

  └─→ 02. 虚拟内存、缺页与 mmap (02-虚拟内存、PageFault与mmap.md)

              └─→ 04. 权限、安全与容器隔离 (04-权限安全与隔离.md)
```

1. **第一阶段：执行上下文与内核边界**：先读 [01-进程线程虚拟内存与系统调用](01-进程线程虚拟内存与系统调用.md)，透彻理解用户态/内核态切换的寄存器保存开销与调度器抢占时机。
2. **第二阶段：内存物理层透视**：深入研读 [02-虚拟内存、PageFault与mmap](02-虚拟内存、PageFault与mmap.md)，掌握 malloc 申请虚拟地址与实际加载物理页的延迟脱节问题。

## 3. 游戏研发与工程落地对接

- **Unreal Engine (UE5)**：
  - UE Pak / IoStore 文件系统：利用 `mmap` 进行资源异步分块流送，结合零拷贝避免重复堆内存分配；
  - 渲染线程与 RHI 线程的 CPU 核心亲和性绑定策略，避免多核频繁迁移导致 L1/L2 缓存不断冷失效；
  - 启动期资源加载预热：通过内存预读减少玩家进入关卡时的即时 Page Fault。
- **游戏服务端**：
  - 游戏服务器物理内存分配治理：在启动阶段对堆内存进行大块预触摸（Memset/Pre-fault），规避在线高峰期发生 Major Page Fault；
  - Linux Dedicated Server 资源限制：使用 cgroups 限制每个房间 DS 进程的 CPU 配额与内存上限，避免单个崩溃波及宿主机。
