## 2. 逻辑学习顺序与依赖关系

1. **第一步：理解对象在内存中的物理排布**
   - 研读 [01-对象布局、虚函数与内存分配](../../知识/01-编程与计算机基础/C%2B%2B语言与对象模型/01-对象布局、虚函数与内存分配.md)；使用 MSVC (`/d1reportSingleClassLayout`) 或 Clang (`-fdump-record-layouts`) 实际输出类布局；掌握单继承、多继承与虚继承下的内存偏移调整（`this` 指针调整）。
2. **第二步：掌握容器内存分配与连续内存优势**
   - 研读 [02-STL容器与Allocator](../../知识/01-编程与计算机基础/C%2B%2B语言与对象模型/02-STL容器与Allocator.md)；掌握标准库分配器接口契约，对比 `std::vector`、`std::deque` 与 `std::list` 的内存拓扑，理解为什么游戏引擎通常禁用链表而选用扁平数组。
3. **前置与后置关联**：
   - 前置依赖：[01-C++核心](../01-C++核心/README.md)（对象生命周期与析构）；
   - 性能延伸：[08-计算机体系结构与性能](../08-计算机体系结构与性能/README.md)（CPU 缓存行与 NUMA 对齐）；
   - 并发结合：[04-C++并发与内存模型](../04-C++并发与内存模型/README.md)（多线程内存分配器锁竞争与 False Sharing）。

## 3. 游戏研发与工程落地对接

- **Unreal Engine (UE5)**：
  - UE 反射体系下的 `UClass` 与 `UObject` 头部开销分析；
  - `FMallocBinned2` / `FMallocBinned3` 垃圾箱内存分配算法与小对象内存池复用；
  - 数据驱动设计（DOD）与 Mass Entity：将包含虚函数的重型面向对象结构打散为平铺 Component，最大化 L1 数据缓存命中。
- **游戏服务端**：
  - 全局内存分配器替代（如集成 Jemalloc 或 Mimalloc），解决多线程高频 malloc/free 引发的全局堆锁竞争；
  - 帧内存分配器（Linear/Frame Allocator）与环形缓冲区：单帧生命周期的临时数据零分配开销。
