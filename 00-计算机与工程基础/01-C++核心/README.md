## 3. 游戏研发与工程落地对接

- **Unreal Engine (UE5)**：
  - `UObject` 的垃圾回收（GC）管理与 C++ 原生 RAII 生命周期的冲突与并存（见 01 篇 3.6 节）；
  - `TArray` 扩容机制中的 `RelocateConstructItems` 与 C++11 `noexcept move` 原理深度互通；
  - `TUniquePtr` 与 `TSharedPtr` / `TWeakPtr` 的引用计数实现与循环引用破除。
- **高性能游戏服务端**：
  - 网络连接（Session/Connection）与业务持锁（LockGuard）的生命周期全生命周期强绑定 RAII，减少资源泄漏；锁次序/等待依赖仍须独立验证；
  - 核心协议消息采用可平凡移动（Trivially Moveable）结构，结合对象池化复用降低系统堆分配频次。
