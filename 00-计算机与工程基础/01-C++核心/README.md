## 2. 逻辑学习顺序与依赖关系

1. **第一步：建立确定性生命周期与资源安全世界观**
   - 研读 [01-C++对象生命周期与RAII](01-C++对象生命周期与RAII.md)；重点掌握 4 种存储期、构造/析构确定性逆序、RAII 守卫模式以及基本/强/不抛异常三档异常安全保证。
2. **第二步：掌握现代 C++ 性能基石——值语义与移动语义**
   - 研读 [02-Copy-Move与值语义](02-Copy-Move与值语义.md)；掌握 Rule of Zero/Five、右值引用绑定规则、移动后对象状态以及 `noexcept` 对 `std::vector` / `TArray` 重分配搬移的关键作用。
3. **后置延伸分类**：
   - 深入内存与虚派发：进阶至 [02-C++对象模型与内存](../02-C++对象模型与内存/README.md)；
   - 深入模板与抽象：进阶至 [03-现代C++与泛型](../03-现代C++与泛型/README.md)；
   - 深入多线程与同步：进阶至 [04-C++并发与内存模型](../04-C++并发与内存模型/README.md)。

## 3. 游戏研发与工程落地对接

- **Unreal Engine (UE5)**：
  - `UObject` 的垃圾回收（GC）管理与 C++ 原生 RAII 生命周期的冲突与并存（见 01 篇 3.6 节）；
  - `TArray` 扩容机制中的 `RelocateConstructItems` 与 C++11 `noexcept move` 原理深度互通；
  - `TUniquePtr` 与 `TSharedPtr` / `TWeakPtr` 的引用计数实现与循环引用破除。
- **高性能游戏服务端**：
  - 网络连接（Session/Connection）与业务持锁（LockGuard）的生命周期全生命周期强绑定 RAII，彻底杜绝资源泄露与死锁；
  - 核心协议消息采用可平凡移动（Trivially Moveable）结构，结合对象池化复用降低系统堆分配频次。
