## 与 UE/服务端的对接

- UE：`UObject` 生命周期由 GC 管理（见 01 篇 3.6）；`TArray` 扩容/`RelocateConstructItems` 与 `noexcept` 移动同源（见 02 篇）。
- 服务端：连接/会话/锁的资源管理全部按 RAII 建模；热路径容器按"可平凡搬移 + 预分配"设计。
