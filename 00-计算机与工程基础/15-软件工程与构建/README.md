## 3. 游戏研发与工程落地对接

- **大型游戏项目构建与资产版本控制**：
  - Git LFS 治理：美术资产（纹理/模型/音频）与代码仓库分离管理，避免 Git `.git` 目录体积暴增导致克隆超时；
  - 虚幻引擎构建加速：集成 FASTBuild / IncrediBuild 实现分布式编译，结合预编译头（PCH）与 Unity Build 技术将客户端编译耗时从 90 分钟压至 15 分钟以内。
- **游戏服务端协议与逻辑健壮性保障**：
  - 协议 Fuzzing：利用 libFuzzer 对服务端外部网关解包函数进行上亿次随机变异变态报文冲击，彻底排查畸形包导致的服务端空指针解引用或内存越界崩溃；
  - 持续集成门禁（CI Gate）：主分支合并前必须通过单元测试、ASan 跑测与全量无 Warning 静态代码检查。
