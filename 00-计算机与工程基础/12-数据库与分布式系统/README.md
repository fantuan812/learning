## 2. 逻辑学习顺序与依赖关系

```text
01. 单机存储与事务原理 (01-存储引擎与事务.md)
  └─→ 02. 分布式理论与共识协议 (02-分布式系统基础.md)
        └─→ 03. 高并发缓存与消息总线 (03-缓存与消息队列.md)
```

1. **第一阶段：吃透单机持久化与事务原子性**：研读 [01-存储引擎与事务](01-存储引擎与事务.md)，理解为何必须在写数据前先刷 WAL 日志，掌握 MVCC 读不加锁如何大幅提升读多写少并发性能。
2. **第二阶段：跨越节点边界，掌握分布式共识**：研读 [02-分布式系统基础](02-分布式系统基础.md)，掌握 Raft 算法多数派（Quorum）选举与日志复制机制，理解分布式事务为何代价高昂。
3. **第三阶段：架构扩展——缓存加速与异步削峰**：研读 [03-缓存与消息队列](03-缓存与消息队列.md)，建立完整的热点数据缓存与异步持久化流水线，掌握消息幂等去重表设计。

## 3. 游戏研发与工程落地对接

- **游戏角色数据存盘与防档回滚**：
  - 角色数据序列化后存盘：采用 Write-Back（内存脏标记 + 定时增量刷盘 + 停服全局全量刷盘）或基于 Redis 的二级缓存，防范单点故障；
  - 涉及钻石、代币和高价值道具的转账与拍卖：严格遵循分布式两阶段提交（2PC）或基于 TCC 的业务型事务，杜绝刷道具与金币凭空消失。
- **世界服架构与跨 Zone 漫游**：
  - 跨进程状态交接：利用 Redis 分布式锁与版本号 CAS 保证角色离开原场景与进入新场景的严格互斥，防止“一人双登”复制装备。
