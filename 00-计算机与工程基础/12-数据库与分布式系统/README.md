# 数据库与分布式系统

本目录连接单机存储与多节点服务，建立可解释、可验证的数据库和分布式系统基础。

## 学习路径

1. 先理解页、日志、索引和事务。
2. 再比较 B+Tree、LSM 与列式存储。
3. 通过 WAL、MVCC 和恢复实验理解故障边界。
4. 学习复制、一致性、共识和时钟。
5. 最后把理论映射到缓存、消息队列和游戏服务端。

## 文档

- [01-存储引擎与事务](01-存储引擎与事务.md)：索引、WAL、MVCC、LSM、恢复和容量分析。
- [02-分布式系统基础](02-分布式系统基础.md)：一致性、共识、时钟、复制、消息与故障处理。
- [03-缓存与消息队列](03-缓存与消息队列.md)：缓存模式、一致性、投递语义、幂等与容量治理。

## 实验建议

- 实现一个带 WAL 的页式 KV 存储。
- 对比 B+Tree 与 LSM 在不同读写比例下的延迟。
- 注入崩溃并验证恢复、幂等和检查点。
- 用网络分区模拟主从切换和脑裂。
- 记录 p50、p95、p99 延迟以及日志增长率。
