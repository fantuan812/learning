## 3. 游戏研发与工程落地对接

- **游戏客户端（UE5 引擎与图形/物理）**：
  - 骨骼动画与摄像机插值：使用四元数球面线性插值（SLERP）保证旋转过程角速度均匀无抖动；
  - 碰撞检测中的分离轴定理（SAT）与 GJK 算法：依赖凸多面体的闵可夫斯基差与点乘投影；
  - 浮点精度边界：在开放大世界大地图中，绝对坐标过大导致低位有效数字丢失（Jittering），分析 UE5 采用双精度大坐标（Large World Coordinates, LWC）的数学必然性。
- **游戏服务端与玩法数值**：
  - 抽卡掉落保底算法：利用非独立同分布伪随机（PRD，如暴击率动态补偿）平滑玩家体验，避免极端脸黑或连续暴击；
  - 联机战斗确定性：利用定点数数学库（Fixed-point Math）代替 IEEE 754 浮点运算，杜绝不同 CPU 架构浮点指令微小差异引发的帧同步不同步（Out of Sync）。
