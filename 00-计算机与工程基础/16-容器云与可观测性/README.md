## 3. 游戏研发与工程落地对接

- **Dedicated Server (DS) 容器化编排**：
  - 基于 Agones 的生命周期管理：玩家匹配成功后向 Agones 请求分配空闲 DS Pod，对局结束前 Pod 处于保护状态（Unhealthy 也不自动驱逐），彻底规避打团时服务器被调度器误杀；
  - 容器内存配额设置：必须留有 20%~30% 缓冲区防范大面积怪物聚集时的瞬时内存峰值，防止触发 cgroups OOM Killer。
- **全局可观测体系建设**：
  - 游戏服务器核心监控大盘：Grafana 展示各服实时在线人数（CCU）、Tick 耗时 P99 / P95、网络丢包率及存盘队列堆积量；
  - 分布式链路追踪：利用 TraceID 将客户端发起的支付、跨服匹配全链路串联，准确定位分布式系统中的微秒级延迟节点。
