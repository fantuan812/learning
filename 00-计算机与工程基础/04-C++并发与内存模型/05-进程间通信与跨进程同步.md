## IPC 机制

1. 进程拥有独立虚拟地址空间。
2. IPC 需要内核或共享映射。
3. pipe 提供单向字节流。
4. FIFO 支持无亲缘进程。
5. socket 支持本机与网络。
6. Unix domain socket 延迟低。
7. TCP socket 提供可靠字节流。
8. UDP socket 提供无连接报文。
9. 共享内存减少复制。
10. 共享内存需要同步协议。
11. mmap 映射文件或匿名页。
12. shm_open 创建 POSIX 对象。
13. Windows section object 类似共享段。
14. 消息队列保留消息边界。
15. eventfd 传递计数事件。
16. signalfd 将信号纳入事件循环。
17. futex 在用户态快路径同步。
18. semaphore 计数资源许可。
19. mutex 保护临界区。
20. condition variable 等待谓词。
21. 命名信号量跨进程可见。
22. 文件锁协调文件访问。
23. advisory lock 依赖参与者遵守。
24. mandatory lock 平台支持有限。
25. 原子 rename 提供提交点。
26. lock-free ring buffer 需内存序。
27. 序列化定义版本与字节序。
28. 长度前缀防止粘包。
29. 校验和检测损坏。
30. CRC 不提供密码学安全。
