## 3. 游戏研发与工程落地对接

- **游戏客户端网络层**：
  - 弱网对抗：移动端游戏在 Wi-Fi 与蜂窝网络切换时，借助 QUIC 连接 ID（CID）实现无感知连接迁移，避免重新走 TCP 握手导致游戏重连黑屏；
  - 帧同步与状态同步包体调优：单个 UDP 报文必须严格控制在 MTU（通常 1400 字节以下），坚决防止 IP 层分片，一旦分片任一片丢失将导致整个报文重传。
- **游戏服务端网络架构**：
  - 客户端连接网关（Gateway）采用一致性哈希（Consistent Hashing）分发长连接会话，确保同一房间或同一玩家的请求稳定路由至指定业务分片；
  - 针对高频短数据帧必须开启套接字选项 `TCP_NODELAY` 禁用 Nagle 算法，消除 40ms~200ms 的无谓攒包延迟。
