## 3. 游戏研发与工程落地对接

- **游戏客户端反作弊**：
  - 核心数值防修改：血量、魔法值、移速在内存中采用异或（XOR）动态混淆与多处冗余校验，防止 Cheat Engine 简单数值搜索篡改；
  - 完整性校验：游戏运行时检测可执行代码段哈希、校验 IAT/EAT 导入导出表与虚函数指针，防止内联 Hook 与 DLL 注入；
  - 资产包防解包：Pak 文件核心资产实施对称加密与数字签名，防止私服盗取资源。
- **游戏服务端协议与鉴权**：
  - 网络报文防重放与防篡改：每个业务数据包追加递增 Sequence ID、时间戳及基于 Session Key 的 HMAC 签名；
  - 权威服务端原则（Authoritative Server）：坚决贯彻“客户端表现、服务端判定”，所有移动、伤害、购买逻辑均在服务端做合法性校验。
