# A* 寻路算法优化（游戏服务器 / 假人 AI）

## 1. A* 基础回顾
- 核心公式：`f(n) = g(n) + h(n)`
  - `g(n)`：起点到节点 n 的实际代价
  - `h(n)`：节点 n 到终点的启发式估计
- 核心流程：
  1. 从 Open List 取出 f 最小的节点
  2. 若为目标节点则重建路径返回
  3. 扩展邻居，计算 g/h，更新或插入 Open List
  4. 重复直到 Open List 为空（失败）
- 性能瓶颈集中在两处：**Open List 操作开销** 与 **扩展节点数量**，优化也从这两条线入手。

## 2. 数据结构优化（收益最直接）
| 问题 | 优化 |
| --- | --- |
| Open List 用数组线性扫描找最小 f | 二叉堆出队 O(log n)；**四叉堆（4-ary heap）** 树更矮、缓存更友好，实测常比二叉堆更快 |
| 堆中节点代价更新（decrease-key） | 记录节点在堆中的下标支持真正 decrease-key；或采用"懒删除"：重复入堆，出堆时跳过过期版本 |
| Closed List 线性查找 | 网格地图用二维 bool/byte 标记数组（O(1)）；不规则图用 HashSet |
| 节点对象频繁 new/释放 | 对象池 / 预分配连续内存；C#、Lua 等有 GC 的环境尤其重要 |
| 节点分散导致缓存未命中 | 节点用连续数组存储，字段按访问频率重排（SoA 布局） |

## 3. 启发式函数选择
- 四方向网格：Manhattan 距离
- 八方向网格：Octile 距离 `max(|dx|,|dy|) + (√2 - 1) * min(|dx|,|dy|)`
- 自由地图：Euclidean 距离（更准但更慢）
- 要求 h 满足**一致性**（`h(n) <= cost(n, n') + h(n')`），保证每个节点至多入队一次，避免重复扩展。
- 权衡：h 越小扩展节点越多；h 过大（不可采纳）搜索快但路径可能非最优。

## 4. 搜索空间优化（减少扩展节点数）
- **JPS（Jump Point Search）**：网格地图利用对称性剪枝，只扩展"跳点"，可比普通 A* 快一个数量级；适用于均匀代价、八方向移动的网格。
- **HPA*（分层寻路）**：地图分块，先搜块级路径再细化块内路径，适合大地图。
- **Navigation Mesh（导航网格）**：用凸多边形代替网格，搜索节点数减少几个数量级，是商业游戏主流方案。
- **双向 A***：起点终点同时搜索，适合 h 不够精确的场景。
- **IDA***：迭代加深、内存占用小但重复计算多，只适合小搜索空间。

## 5. 工程级优化（服务器场景重点）
- **提前终止**：达到最大搜索节点数 / 时间预算时返回当前最优路径或降级方案（直线 + 简单避障）。
- **路径缓存**：按 (起点格子, 终点格子) LRU 缓存；目标不变、起点小幅变化时尽量复用。
- **路径平滑**：A* 结果用 string pulling / funnel 算法拉直，减少假人拐弯、抖动，同时降低重规划频率。
- **寻路频率控制**：
  - 按需寻路：目标变化才搜，不要每 Tick 都搜；
  - 失败冷却：寻路失败后指数退避重试；
  - 距离阈值：目标很近时直接走向目标，不启动寻路。
- **Tick 预算 / 时间片**：每 Tick 给寻路分配固定毫秒预算，把任务排队分批执行，防止单帧尖峰。
- **批量与优先级**：同区域假人共享区域级路径；玩家附近的假人（对体验影响大）优先。
- **增量寻路**：地图动态变化（障碍物增删）时使用 D* Lite 复用上次搜索结果。

## 6. 微优化
- 热路径避免虚函数、委托/闭包、动态绑定调用。
- 局部变量缓存成员变量，避免反复解引用。
- 避免在热路径做字符串拼接、日志输出、内存分配。
- 邻居遍历用预计算偏移表，减少 if 分支。
- 编译时开优化等级并保留调试符号（-g），方便后续 perf 分析。

## 7. 验证与调优流程
1. 插桩统计各阶段耗时：入队 / 出队 / 邻居扩展 / 启发式计算 / 路径重建。
2. perf 采样确认热点与调用链，查漏（分配、缓存缺失、锁竞争）。
3. 同一场景、同一批假人、同一起终点，优化前后对比。
4. 关注指标不止单次寻路耗时，还有：寻路次数、平均扩展节点数、Open List 平均长度、GC 分配量。

## 8. 常见误区
- 只调启发式不动数据结构：若热点在 Open List 操作，改 h 没有用。
- 浮点比较不做 epsilon 处理，导致节点反复入队出队。
- 优化破坏了 h 的可采纳性/一致性，假人出现明显绕路。
