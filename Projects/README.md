# Projects —— 项目专用知识

项目专用（project / mixed 中的项目部分）知识放在本目录，按项目名分子目录，例如：

```text
Projects/
├─ <ProjectName>/
│  ├─ Architecture.md
│  ├─ Decisions.md
│  └─ ...
```

通用原理先链接到既有领域主文；项目约束、部署配置和验收结论放在明确项目目录。只有通用部分可独立复用且拆分不破坏叙事时才 Split，并保留来源与互链；不机械拆分所有 mixed 文档。

[系统实战](../系统实战/README.md) 承载跨域端到端教学链路，不因含代码或“项目”字样就迁入本目录。每个项目应链接其原理依据与实际证据；缺少运行结果不能声称已经验收。

整体职责见 [知识库架构](../references/知识库架构.md)。
