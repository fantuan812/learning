# Knowledge —— 通用知识（Canonical）

通用知识（universal）的受控扩展入口，现有六个领域继续承载其各自的 Canonical 正文。

先从 [领域 MOC](../00_Index/domains/README.md) 查找已有主题。只有确认独立新领域、记录分类决定并建立导航后，才在本目录扩展；尚未确定的材料保留在 Inbox。本目录不承接六个领域的机械搬迁，也不复制第二套分类树。

规则：

- 一个概念只有一个 Canonical Location，其他位置只放链接；
- 新条目先入 [Inbox](../Inbox/README.md)，按 knowledge-base-organizer 流程处理；
- 分类前先查 [.kb/taxonomy.yaml](../.kb/taxonomy.yaml) 与 [.kb/aliases.yaml](../.kb/aliases.yaml)。

职责依据：[知识库架构](../references/知识库架构.md)与[知识边界与生命周期](../00_Index/axes/知识边界与生命周期.md)。
